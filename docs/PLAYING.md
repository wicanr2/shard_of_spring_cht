# 玩《春之石》繁體中文版

這個引擎不附帶遊戲資料。它讀的是**你自己那份原版**裡的怪物表、法術表、
地圖與美術 —— 所以第一次執行之前要先跑一次轉換器,把原版的檔案轉成
引擎讀得懂的格式。整個流程大約一分鐘,只需要做一次。

## 下載的那一包裡有什麼

**Linux 是一個 AppImage**,下載、加執行權限就能跑,不用解壓縮:

```
chmod +x shard-of-spring-cht-<版本>-linux-x86_64.AppImage
```

Windows 與 macOS 是壓縮檔,裡面長這樣:

```
shard-of-spring-cht-<版本>-<平台>/
├── shard             引擎(Windows 是 shard.exe)
├── shard-convert     轉換器(Windows 是 shard-convert.exe)
├── translations/     譯文,轉換器會自己找,不用管它
├── PLAYING.md        這一份
└── README.md
```

macOS 那一包是 **universal**,Intel 與 Apple Silicon 共用同一支。

## 你需要準備的

**一份合法的 MS-DOS 版《Shard of Spring》。** 解開之後會看到一個
`sharspri` 資料夾,裡面有一百個檔案,總共約 420 KB。認得出來的長這樣:

```
sharspri/
├── START.EXE      MENU.EXE      TOWN.EXE      CMBT.EXE   …
├── MONSTERS.DAT   SPELLS.DAT    ITEMS.DAT     TOWNDATA.DAT
├── CHARS.DAT      GROUPS.DAT    TOWNDATA.BIN  WRLDMAP.BIN
├── DG1MAZE.SQZ    DG2MAZE.SQZ   …            DE1EFF.BIN …
└── PICT1.BIN      MONST1.BIN    …
```

⚠ 有些版本把檔名存成小寫。轉換器認的是**大寫**檔名,小寫的話先改名。

⚠ **不要**把引擎指向你的原版資料夾去玩 —— 引擎要寫存檔,而原版那份是
你的母片。轉換器會把存檔複製一份到別的地方(見下面第 2 步)。

## 1. 轉檔

**Linux(AppImage)** —— 資產與存檔會放進 `~/.local/share/shard-of-spring/`,
你不用選位置:

```
./shard-of-spring-cht-<版本>-linux-x86_64.AppImage --convert /路徑/sharspri
```

轉完直接雙擊或再跑一次就進遊戲。**下面第 2、3 節講的路徑對 AppImage 不適用** ——
它的存檔在 `~/.local/share/shard-of-spring/saves/`。

**macOS** —— 在解壓縮出來的那個資料夾裡:

```
./shard-convert -in /路徑/sharspri -out assets
```

Windows 開 PowerShell 或命令提示字元,`cd` 到那個資料夾:

```
.\shard-convert.exe -in C:\路徑\sharspri -out assets
```

從原始碼跑同一支程式(需要 docker):

```
tools/go.sh run ./cmd/convert -in /路徑/sharspri -out assets
```

轉完會列出每一項的數量,像這樣:

```
monsters   74
spells     33
items      57
tiles      …
mazes       6
```

哪一項是 0 或直接報「讀不到原版檔」,就表示那個檔案不在 `-in` 指的資料夾裡。
**訊息會寫出缺哪一個檔** —— 照著補齊再跑一次就好,不必從頭來過。

轉出來的 `assets/` 不到 1 MB,包含:

| 資料夾 | 內容 |
|---|---|
| `assets/data/` | 怪物、法術、道具、地圖、迷宮、房間文字(JSON)|
| `assets/gfx/` | 圖塊、大圖、怪物(PNG)|
| `assets/save/` | 原版磁片附的那五支隊伍,**當作起點用**(不是你的存檔,見下)|

## 2. 存檔放在哪裡

**你的進度存在 `saves/party.json`**,位置是**資產資料夾的旁邊** ——
照上面的做法轉檔的話,就在你解壓縮出來的那個資料夾裡:

```
shard-of-spring-cht-…/
├── assets/            轉出來的資產
│   └── save/          原版那五支隊伍(起點)
└── saves/
    └── party.json     ★ 你的進度
```

存檔是 JSON,看得懂也改得動。要備份,複製 `saves/` 就夠了。
`-save /別的/路徑` 可以改到別的地方。

⚠ **`assets/save/` 不是你的存檔。** 那是轉檔時從原版複製過去的起點資料,
重跑轉換器**會**覆蓋它 —— 但那不影響 `saves/` 底下的進度。

## 3. 開始玩

```
./shard -assets assets
```

Windows:

```
.\shard.exe -assets assets
```

⚠ **macOS 第一次要右鍵 →「打開」**,直接雙擊會被擋下來。這一包**沒有簽章**
(它是在 Linux 上交叉編出來的,簽章要 Apple 的機器),
所以 Gatekeeper 會說「無法驗證開發者」。指令列的等價做法:

```
xattr -dr com.apple.quarantine shard shard-convert
```

從原始碼跑:

```
tools/go.sh build && ./build/shard -assets assets
```

畫面是 1024 × 768。美術做 4 倍整數放大(不模糊),文字另外用向量字型畫,
所以中文不會糊掉。

第一次進去會看到標題,然後是主選單。**原版沒有「開新遊戲」這個選項** ——
它的做法是先用 `C)har Utilities` 造角色、編隊,再用 `L)oad a Party` 載入。
中文版照原樣保留這個流程。

原版磁片附了一支已經玩到一半的隊伍(第 5 隊),想直接看遊戲長什麼樣,
載入它最快。

### 按鍵

畫面最下方那一列**永遠寫著現在這個畫面能按什麼** —— 換一個畫面就換一組。
下面只列幾個「原版有、位置不太一樣」的:

| 場合 | 按鍵 |
|---|---|
| 世界地圖 / 地城 | 方向鍵或 `1`–`4` 移動(**先轉再走**:面向不同時第一下只轉身)|
| 世界地圖 | `C` 紮營、`P` 隊伍資訊、`N` 名冊、`S` 存檔、`Q` 離開回主選單 |
| 城鎮建築清單 | 字母進建築、`Z` 營地、**數字看角色卡**、`ESC` 離開 |
| 營地 | 十一個指令各一個字母,`ESC` 拔營 |
| 戰鬥 | `A` 攻擊、`C` 施法、`U` 用道具、`D` 驅散、`/` 檢視、`Enter` 結束這一輪 |
| 施法 | 選法術 → 輸入投入點數 → 方向鍵移動游標 → **`PgDn` 施放** |
| 檢視面板 | `←` `→` 換單位、`ESC` 關閉 |

⚠ 原版走的是小鍵盤模板(`2/4/6/8` 移動、`0` 攻擊)。中文版以方向鍵為主,
字母鍵盡量照原版;**不一樣的地方提示列都會寫**。

⚠ 遊戲裡有兩行「⚠ …未解」的字,那不是錯誤訊息:
是**還沒逆向出來的規則**,寫在畫面上讓你知道哪裡與原版不同
(一場遭遇的怪物隻數、怪物施法)。

### 音樂

原版全遊戲只有兩首曲子:通關曲與死亡曲。世界地圖、地城、城鎮**本來就是安靜的** ——
1986 年的 PC 喇叭遊戲多半如此。

中文版另外寫了六首場景配樂(標題、城鎮、世界地圖、地城、戰鬥、最終戰),
用的是原版同一套方波音源,所以聽起來同源。**預設不開** ——
第一次玩聽到的是原版的樣子。

八首曲子(六首場景配樂 + 原版兩首)都以 OGG 收在執行檔裡,不用另外下載。

**按 F5** 循環切換:

```
原版 → 重製 → 關閉 → 原版 …
```

設定記在 `saves/config.json`,下次開起來還在。
戰鬥中的 `S` 是原版的音效總開關,與 F5 是兩回事。

### 字型

預設會依序尋找系統上的中文字型。指定其他字型:

```
./shard -assets assets -font /路徑/某個字型.ttf
```

找不到任何中文字型時畫面會是一堆方框 —— 那不是壞掉,是缺字型。

## 4. 開機的手冊查表題

原版開機會問一題「手冊第幾頁第幾行第幾個字」的防拷問題。
中文版沿用原版的流程,**直接按 Enter 就過**。

## 常見問題

**轉換器說「讀不到原版檔」。**
`-in` 沒有指到 `sharspri` 那一層,或檔名是小寫。訊息裡會寫缺的是哪一個檔。

**畫面全是方框。**
系統上沒有中文字型,用 `-font` 指一個。

**視窗太小 / 太大。**
畫面是固定的 1024 × 768,由視窗管理員縮放。

**我想從頭玩。**
刪掉 `saves/`(不是 `assets/save/`)。下次進去就會從原版那五支隊伍重新開始。
⚠ 這會刪掉你的進度,先備份。

**macOS 說「無法驗證開發者」/ 打不開。**
第 3 節。右鍵 →「打開」,或跑一次 `xattr -dr com.apple.quarantine`。

**轉出來的字都是英文。**
轉換器沒找到 `translations/`。它會在執行檔旁邊、目前目錄、`/translations`
依序找 —— 三個都沒有的話它會印一行警告然後轉出英文版。
把 `translations/` 放回執行檔旁邊,或用 `-translations` 指位置,重跑一次。

**地城裡什麼都看不見。**
那是正常的:地城要光源。到營地用照明法術(魔法火炬 / 水晶光),
火把每走一步燒掉一回合,燒完視野就縮回去。回到地面火把會熄掉,不會留著。
