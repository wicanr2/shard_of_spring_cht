# `GROUPS.DAT` — 隊伍/存檔記錄 — **READY**

5 筆 × **90 bytes**。`OPEN … mov cx, 5Ah`;`450 ÷ 90 = 5` 整除。
⚠ **出貨檔整份是空白**(450 個 `0x20`)—— 所有語意都來自程式碼,資料側無訊號。

> 2-byte 整數欄位**全部落在奇數位移**(與 `CHARS.DAT` 相反)。

| 位移 | 語意 | 信心 |
|---:|---|---|
| 23 | 補給品(隊伍層級)| 證據充分 |
| **25** | **下次遭遇檢查前的剩餘回合**(歸零時掃 3×3 鄰域)| 證據充分 |
| 27 / 29 / 31 | 時鐘:**月 / 日 / 時** | 已確認 |
| 33 | 時以下的計數(不顯示)| 已確認 |
| 35 / 37 | 世界座標 x / y | 已確認 |
| 41 | 朝向(`1`北 `2`東 `3`南 `4`西)| 已確認 |
| 45 | 光源剩餘回合 | 證據充分 |
| 59 / 61 | **有光 / 無光**時的能見度 | 已確認 |
| 79 / 81 | 迷宮座標 x / y(1-based,索引時 y−1)| 已確認 |
| 83 | 選自然光(天色)還是攜帶光 | 證據充分 |
| 85 | 逃跑旗標(全隊離場時清 0)| 已確認 |

## 時鐘的四級進位

```
位移 33 (1–10) → 位移 31 (4–26) → 位移 29 (1–34) → 位移 27 (1–21)
每次推進另外 dec 位移 25
```

⚠ **上限 10 / 26 / 34 / 21 不是地球曆法。**
「一天幾小時、一月幾天」**未解且不可從這些數字推**——
remake 只能照抄計數器,不要做單位換算。

## 天色與光源

```
自然光 ds:35B4h ← 由「時」決定:≥17 → 2、≥19 → 1
攜帶光 ds:35B2h ← 光源計數 >0 → 位移 59;≤0 → 位移 61 並把計數歸 0
位移 83 決定用哪一個
```
