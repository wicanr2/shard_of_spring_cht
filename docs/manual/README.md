## ⚠ 讀這份手冊前必須知道的三件事

### 1. 內文是從 Apple II 版翻譯的,沒有為 PC 版校訂

封面印 `FOR PC`、磁片標籤印 `1987 For IBM PC/XT/AT; 384K`,
但**手冊 p.4 正文寫「你必須有 APPLE Ⅱ 64K 的記憶容量」**。

所以**不能整本當成 DOS 版的規格**。判準
([`re/125`](../re/125-manual-confirms-spells.md) §1):

> 每一項數值都要與 DOS 版的資料檔**逐項比對過**才算印證,
> 不能因為前一項對上就推定整章都對。對不上時第一個假設是平台差異,
> 但那個假設同樣要有證據,不能當萬用藉口。

### 2. 原文自己有幾處不一致,抄錄一律照原樣保留

| 位置 | 情況 | 裁決 |
|---|---|---|
| `MAGIC TORCH` 消耗 | p.26 正文寫 2、p.28 表格寫 3 | 資料檔是 **2** → p.28 表格印刷錯誤 |
| `RESURRECT` 拼法 | p.28 拼 `Resurrect`、p.29 拼 `RESSURECT` | 資料檔是 `RESURRECT` |
| p.39 | 印成「睦過覺」 | 應為「睡過覺」,照原樣抄 |
| p.38 | 印成 `WIND WAIK` | 應為 `WIND WALK`,照原樣抄 |

### 3. 遊戲截圖裡的數字判讀信心低,不要拿來當證據

點陣字型在印刷後掃描,`P`/`F`、`o`/`d`/`q` 難以區分。
已知的分歧:同一個截圖角色名被三份抄錄分別讀成
`Autocue` / `Autodue` / `Autoque` — **未裁決**,因為那是手冊作者自己的存檔角色名,
不是遊戲資料,對 remake 沒有影響。

⚠ **但截圖裡的商店價目表是例外** —— 那是遊戲畫出來的資料,
而且已經用它裁決過一次([`re/126`](../re/126-shop-price-multiplier.md))。
判準是:**截圖裡屬於「遊戲資料」的部分可用,屬於「這一局的狀態」的部分不可用。**

## 還沒拿去核的表

p.47–49 的附錄表格數量最多,**都還沒逐項對照資料檔**:

- 經驗等級表(`Experience Levels`)
- 速度 → 移動數 / 攻擊次數(`Effects of Speed`)
- 力量 → 傷害加值(`Bonus Damage by Strength`)
- 智力 → 法力成長上限(`Max S.P. Gain per Level`)
- 耐力 → 生命成長上限(`Max H.P. Gain per Level`)
- 降魔成功率矩陣(`% Chance of Priest Dispelling`)
- 五種族的職業限制與屬性加值(`Race Advantages/Disadvantages`)

⚠ 其中**力量 → 傷害加值**最值得先核:
[`spec/01-combat.md`](../spec/01-combat.md) §5 的傷害公式有兩個係數
`k₁`/`k₂`「來源未解」,而手冊這張表給了一個具體的候選形狀
(`bonus = floor((STR − 7) / 2)`,3–20 全部吻合)。
**但那只是形狀吻合,還沒回 IDA 確認 `ds:9464h` 是不是從屬性 6(力量)算出來的**
—— 在讀到那段程式碼之前,這仍然是**假設**。

## 譯名:1987 年的官方前例與本專案 glossary 衝突

手冊有一整套精訊的官方譯名,與
[`translations/glossary.md`](../../translations/glossary.md) 多處不同:

| 英文 | 精訊 1987 | 本專案現行 |
|---|---|---|
| `FIRE RUNES` / `METAL RUNES` | 火誌 / 金誌 | 火之符文 / 金之符文 |
| `MELT` | 溶解術 | 融化術 |
| `SWORD`(法術) | 劍術 | 劍刃術 |
| `WARRIOR` 職業 | 戰士 | 勇者(對應 `CHARS.DAT` 的 `Hero`)|
| `YMROS` / `SIRIADNE` / `RALITH` | **保留英文大寫** | 音譯 |

最後兩列是**方向性衝突**:精訊的專有名詞不譯,而 glossary 硬規則 4 是一律音譯;
職業名精訊用「戰士」,而本專案把「戰士」留給怪物 `Fighter`。

**待專案負責人裁決**,結論回填 glossary。
