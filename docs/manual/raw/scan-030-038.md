2 魔法物品(MAGICAL ITEMS)

在YMROS島上可以發現許多形式的魔法物品,如指環(RINGS)、魔杖(
STAVES),和藥劑(POTION)等。這些物品可以一直施出魔法力量直到用壞
了為止;但藥劑僅僅能使用一次。魔法物品提供了法術所需的力量,戰士和巫師都
能用得一樣好。

## ScanImage036 — 手冊 p.32

五 野外探險:

當你在野外行走時,請格外留意時間是一個很重要的因素,你的視野寬廣或狹小
是依太陽的起落而定的,晚上,如果你不肯去睡覺,時間到了便會被迫紮營,不睡過
覺是不能離營的。在這裏的曆法是一年有22個月,每月有34天,而一天又分為26個小
時。一年的開始是SPIRIT這個月,而最後一個月則是COMET。

在野外,你的人物可以面向你(SOUTH)行走,當他面向你時,可以看見他的
衣領。戰士是以右手的劍來攻擊他面前的敵人。下面便為你介紹在野外所用的指令:

〔方向鍵圖示:左轉〕 向左轉,不是向西行走。

〔方向鍵圖示:右轉〕 向右轉,亦非向東前進。

〔方向鍵圖示:後轉〕 向後轉,但不是向南走。

RETURN 向你目前所面對的方向前進。在丘陵上行走時間會過得比原來快兩
倍。有些門你必須要有在地下城找到的鑰匙才能通過。

C 紮營。在營地裏,你可以裝備你的隊員,檢查他們的狀況,詳細指令在第八
章會有介紹。

P 顯示隊員排列的位置和現在的時間。

S 存下遊戲,除了在城市、營地、和戰鬥時不能做此功能之外,即使在地下城
也可以存下遊戲狀況。存下狀況後你仍可以繼續進行遊戲,因此最好是經常
使用這個存錄狀況。

## ScanImage037 — 手冊 p.33

六 戰鬥

當你在野外或地城中冒險時,將會遭遇到許多怪物的攻擊,這時,你所處的位
置會被放大成15×15格的戰鬥畫面,戰場是由許多圓點所圍成,這些圓點都可以讓你
逃離戰場。只要你的隊員中有人走上了這些圓點!這個點馬上變成了一個四個方向箭
頭的出口,其他的隊員便只能再從這個出口出去,然後便避開了這場戰鬥。

在THE SHARD OF SPRING中,護甲可以替穿戴者承受許多的傷害。例如,
一個戰士穿戴了具有5點防護能力的PLATE ARMOR,敵人對他施予7點的傷害,
那麼他實際受的傷害便只有2點,如果他還有ARMOR SKIN的技能,還可以再減去
2點的傷害。也就是說,他根本就沒受傷,護甲已承受了他所有的傷害。

## ScanImage038 — 手冊 p.34

在戰鬥中,移動的先後順序是依速度(SPEED)而定的,速度最快的先走,速
度最慢的只好最後一個行動。每一個行動都要耗去一定數字的移動點數(MOVEMENT
POINTS),而人物的移動點數則和速度(SPEED)一樣。指令如下:

| 指令 | 消耗點數 | 行動 |
|---|---|---|
| RETURN | 2 | 向前前進一格,顯示窗的右上方有個箭號表示你目前所面對的方向。 |
| 〔方向鍵圖示:左轉〕 | 1 | 向左轉。 |
| 〔方向鍵圖示:右轉〕 | 1 | 向右轉。 |
| 〔方向鍵圖示:後轉〕 | 1 | 向後轉。 |
| A | 3 | 攻擊面前的敵人,攻擊時有些微小的機會對敵人造成加倍的傷害,這時底下顯示部分會以「HACKS」這個字來代替「HITS」以表示你給予敵人加倍的傷害。如果有BERSERKING的技能,造成加倍傷害的機會便會提高很多。 |
| C | 3 | 施法(詳見第四章的法術部分)。施法時必須先鍵入所要施用法術的全名,當然,你的身上要有該類法術的技能標誌,再決定要用多少S.P.。然後螢幕會出現一個游標,用I,J,K,M移動游標到〔本頁在此處截止,下接下一頁,不在本次抄錄範圍內〕 |
