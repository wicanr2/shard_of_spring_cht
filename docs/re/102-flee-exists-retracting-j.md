## 結論

**J = RE-DONE** —— **兩篇都撤回。看板退回 10/12。**

## 1. 證據

```
0x9556  描述子 → 'PARTY RAN!'      (與 0x9516 的 'PARTY DIES!' 相鄰)

0122A9  mov bx, 9556h              ; 'PARTY RAN!'
0122AC  INT 3F:6E                  ; 串接顯示
0122CD  mov word ptr ds:3532h, 0   ; ★ GROUPS.DAT 位移 85 清為 0
```

`0x122A9` 就落在 [`95`](95-no-flee-command.md) §2 我判成「**全隊死亡**的出口」
那個叢集(`0x12206`–`0x12230`)裡 ——
**那個叢集是兩個出口共用的**:全滅走 `PARTY DIES!`、逃跑走 `PARTY RAN!`,
兩者都是回到地圖模組。

## 2. 根因:正規表示式少一個字

[`95`](95-no-flee-command.md) §1 掃的是:

```python
r'flee|run|escap|away|surrender|retreat|initiat|first|order'
```

**有 `run`,沒有 `ran`。** `'PARTY RAN!'` 不含 `run`,整條線一開始就漏了。

而 §2「只有兩個模組轉交叢集」的推論**本身沒錯**,錯在把「兩個叢集」
讀成「兩個出口」—— **一個叢集裡可以有兩個出口**,我沒有進去看。

## 3. ⚠ 正對照沒有救到我,而它本來應該要

[`95`](95-no-flee-command.md) §4 做了正對照,結論是「方法在同一批檔案上持續有輸出」。
**那個正對照是對的,但它證明的是錯的東西。**

> **判準:正對照要對「這一次的查詢」做,不是對「這個方法」做。**
> 我證明的是「字串搜尋這個工具會出結果」,
> 而需要證明的是「**這一組關鍵字**抓得到我要找的東西」。
> 正確的正對照是:**先找一個已知存在的同類目標,看這組關鍵字抓不抓得到** ——
> 例如拿 `'PARTY DIES!'`(死亡,已知存在)去測,
> 那組關鍵字裡的 `flee|run|escap|away|retreat` **一個都不會命中**,
> **當場就會暴露關鍵字太窄。**

這是本專案第二次栽在「查詢回空」上,
而第一次([`70`](70-key-chains-all-modules.md) §6)的教訓是「先問工具的分母」——
**這次分母沒問題,問題在查詢式本身。兩者要分開檢查。**
