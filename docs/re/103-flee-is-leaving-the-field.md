# 103 — 逃跑是「全隊離場」,J 重新收斂

日期:2026-08-14
接續:[`102-flee-exists-retracting-j.md`](102-flee-exists-retracting-j.md)
子系統:**J. 戰鬥規則**

## 結論

**逃跑不是一個指令,是一個狀態:隊伍成員全部離開戰場。**

```
012240  mov word ptr ds:9552h, 0     ; 旗標歸零
012246  mov ax, ds:34F8h             ; 隊伍人數
012249  add ax, 8                    ; 上界 = 人數 + 8
01224F  mov ax, 9                    ; i 從 9 開始
012256  add ax, 96h                  ; + 150 = 10 × 15 → 屬性 10(朝向)
01225D  cmp word ptr [di+6822h], 0
012262  jg  → 0x12267
012267  mov word ptr ds:9552h, 1     ; 只要有一個朝向 > 0 → 旗標 = 1
012277  cmp ax, ds:9554h / jle       ; 迴圈到上界
01227D  cmp word ptr ds:9552h, 0
012282  jz  → 'PARTY RAN!'           ; 一個都沒有 → 全隊跑了
```

**掃描單位 9 到「人數 + 8」,看有沒有任何一個的朝向 > 0。
一個都沒有 → `PARTY RAN!`。**

## 1. 索引範圍自己驗證了自己

迴圈從 **9** 開始、上界是 **`ds:34F8h` + 8**。
[`43`](43-common-block-and-array-indexing.md) 早就寫過**戰鬥時隊伍佔第 9–13 欄** ——
若 `ds:34F8h` 是隊伍人數(最多 5),上界正好是 **13**。

**兩個獨立來源給出同一個範圍。**

## 2. 朝向 `0` = 不在場

屬性 10 是朝向([`96`](96-facing-and-action-points.md)),有效值 `1`–`4`。
**`0` 不是任何一個方向** —— 它是「這個單位不在戰場上」的標記。

所以逃跑的完整機制是:

1. 成員各自移動,走出戰場的那個朝向被清成 `0`
2. 每回合檢查一次:隊伍索引 9…人數+8 裡還有沒有朝向 > 0
3. 一個都沒有 → 顯示 `'PARTY RAN!'`
4. `GROUPS.DAT` 位移 85(`ds:3532h`)清為 `0`([`102`](102-flee-exists-retracting-j.md) §1)
5. 走 `0x12206` 叢集回地圖模組
