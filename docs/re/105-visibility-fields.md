# 105 — `GROUPS.DAT` 位移 59 / 83:能見度與它的來源選擇

日期:2026-08-14
接續:[`104-groups-fields-from-context.md`](104-groups-fields-from-context.md)
子系統:**D. 角色/隊伍資料**

## 結論

`USERLIB` 槽 33(狀態列/遊戲內時鐘,[`66`](66-userlib-slot-semantics.md))
在 `0x10CB6` 起只讀四個 DS 變數,其中兩個正是待解的欄位:

```
ds:3534h  ← GROUPS.DAT 位移 83
ds:35B2h  /  ds:35B4h        ← 兩個候選值
ds:3078h
```

而存檔常式(`USERLIB 0x1080D`)做的是**同一件事**:

```
0x1080D  cmp word ptr ds:3534h, 63h   ; 99
0x10817  mov ax, ds:35B4h  →  ds:3060h    ; 相等
0x10820  mov ax, ds:35B2h  →  ds:3060h    ; 不等
```

`ds:3060h` = **位移 59**。

| 位移 | 語意 | 信心 |
|---:|---|---|
| **59** | **能見度**(狀態列的 `Visibility =`)| 證據充分 |
| **83** | **選擇能見度來源的模式旗標**(`99` → `ds:35B4h`,否則 `ds:35B2h`)| 證據充分 |

## 1. 為什麼判成能見度

槽 33 引用的五個字串是
`Hour:` / ` Day:` / `  In the Month ` / `Visibility =` / ` Player's Clock:`
([`66`](66-userlib-slot-semantics.md) §2)。

**槽 33 只讀四個 DS 變數**,而其中三個(`ds:3534h`、`ds:35B2h`、`ds:35B4h`)
組成一個「二選一」—— **狀態列上唯一需要「依情境二選一」的欄位就是能見度**
(地面與迷宮的可視範圍不同)。時、日、月不需要選。

⚠ **這是消去法,不是直接證據。** 我沒有看到「`ds:3060h` 被印在 `Visibility =` 後面」
那一行。**標證據充分,不標已確認。**
