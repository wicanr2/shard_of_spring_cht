# 119 — 屬性 12 在戰鬥中從不遞減:位移 84 的判讀失去主要支柱

日期:2026-08-14
接續:[`118-daylight.md`](118-daylight.md)
子系統:**D. 角色資料** × **J. 戰鬥規則**

## 結論

掃 `CMBT` 裡對戰鬥屬性做 `dec` / `sub` 的**全部** 50 處:

```
屬性 1, 3, 4, 5, 7, 8, 10, 11, 13, 14, 17, 18   ← 有
屬性 12                                          ← 一處都沒有
```

**[`111`](111-status-code-equals-school.md) §2 把位移 84 判成「狀態剩餘回合」,
理由之一是「一個狀態效果需要『是什麼』+『還剩多久』」——
而那個『還剩多久』在戰鬥裡從來沒有被減過。**

## 1. 正對照

同一支掃描在同一個檔案上找到 **12 個相異屬性的 50 處** `dec`/`sub`,
包括 [`83`](83-hp-is-attribute-3.md) 已驗證的
「屬性 3(生命值)在 `0x13A14` 被 `sub`」——**方法有效**。

所以「屬性 12 沒有遞減」是真的空,不是掃描失效。

⚠ 但這**只涵蓋 `CMBT`**。狀態效果在戰鬥外也會走時間
(`CAMP` 有 `'That character is incapacitated.'`),
**遞減可能在別的模組**。本輪沒掃其他模組。

## 2. 位移 84 的判讀現在是什麼

| 仍然成立 | 失去支持 |
|---|---|
| 屬性 12 與屬性 8(狀態)**在同一條指令序列裡被寫**([`111`](111-status-code-equals-school.md) §1)| 「剩餘回合」需要有人減它 —— `CMBT` 裡沒有 |
| 五個預設角色的位移 84 全為 0,而狀態也全為 `OK` | |

**位移 84 = 與狀態同時被設定的一個值。**
「**剩餘回合**」降為**假設**;它也可能是**強度**、**施法者**、**來源法術**。

> **判準:一個「X 需要有 Y」式的論證,要去找 Y 存不存在。**
> [`111`](111-status-code-equals-school.md) §2 用「狀態需要持續時間」推出語意,
> **卻沒有去找那個持續時間被誰減** —— 而那正是這個論證唯一可以被否證的地方。
> **從設計常識推出來的東西,一定有一個對應的程式碼事實可以驗;
> 沒去驗就等於只是複述常識。**
