# 126 — `TOWNDATA.DAT` 的商店價格倍率:由手冊截圖裁決出來的新欄位

日期:2026-08-14
接續:[`125-manual-confirms-spells.md`](125-manual-confirms-spells.md)、[`53`](53-world-tiles-towns-and-draw-renderer.md)
子系統:**E. 規則資料表**(`ITEMS.DAT` 欄 3 的語意)/ **F. 世界地圖**(`TOWNDATA.DAT` 欄位)
輸入:`TOWNDATA.DAT`、`ITEMS.DAT`(SHA-256 見 [`00-inputs.md`](00-inputs.md))
+ 手冊 p.31 的遊戲截圖

## 結論

`TOWNDATA.DAT` 每筆商店記錄的**位移 38 是一個 MBF 單精度浮點 = 該店的價格倍率**。

`ITEMS.DAT` 欄 3 是**基準價**,不是玩家看到的售價;
售價 = `INT(基準價 × 該店倍率)`。

**信心等級:已確認** —— 4/4 精確吻合,而且吻合的方式包含一個
**只有正確假設才會產生的細節**(§3)。

## 1. 起點:一組對不上的數字

手冊 p.30 的護甲表與 `ITEMS.DAT` 欄 3 **防護值全對、價格全錯**:

| 護甲 | 防護值(手冊/檔案) | 價格(手冊) | 價格(`ITEMS.DAT` 欄3) |
|---|:-:|---:|---:|
| Cloth | 1 / 1 ✅ | 5 | 5 |
| Leather | 2 / 2 ✅ | 10 | **15** |
| Chain | 3 / 3 ✅ | 20 | **40** |
| Scale | 4 / 4 ✅ | 75 | **200** |
| Plate | 5 / 5 ✅ | 200 | **400** |

同一頁的武器表則是傷害與價格**全部 8/8 相符**。

「防護值對、價格不對」排除了「抄錯欄位」;
「武器全對、護甲全錯」排除了「整張表是別的平台」。

## 2. 裁決:用手冊裡的遊戲截圖

手冊 p.31(`ScanImage035`)有兩張店內截圖,**那是第三個來源**
——不是手冊編者寫的表,是遊戲自己畫的畫面。

| 店 | 品項與售價 | 對 `ITEMS.DAT` 欄3 |
|---|---|---|
| **Athe / The Blacksmith** | Dagger 2、Small axe 6、Short sword 15、Mace 13、Morning star 20、Broad sword 30、Battle axe 65、2-hand sword 100、Mace+1 350、Sword+1 500、Axe+1 750、Sword+2 950、Cloth 5 | **13/13 完全相同** |
| **Atlantis / Enchanted Armor** | Chain+1 909、Scale+1 1299、Plate+1 1949、Plate+2 2599 | 檔案是 700 / 1000 / 1500 / 2000 |

比值:909/700、1299/1000、1949/1500、2599/2000 = **1.2986 / 1.2990 / 1.2993 / 1.2995**。

一家 1.00 一家 ~1.30 —— 這不是版本差異,是**每家店有自己的倍率**。

## 3. ⭐ 倍率就在 `TOWNDATA.DAT` 裡,而截斷誤差證明了它

[`53`](53-world-tiles-towns-and-draw-renderer.md) 定出 `TOWNDATA.DAT` = 61 筆 × 45 bytes
(城鎮名 16 + 商店名 16 + 13 bytes 二進位)。把那 13 bytes 的**位移 6**
(= 記錄位移 38)當 MBF 單精度解讀,61 筆全部得到 0.6–2.0 的乾淨數值:

```
Atlantis / Enchanted Armor   66 66 26 81  →  1.2999999523162842
Athe     / The Blacksmith    00 00 00 81  →  1.0
```

| 品項 | 基準價 | × 1.2999999523 | `INT()` | 截圖 | |
|---|---:|---:|---:|---:|:-:|
| Chain +1 | 700 | 909.999967 | **909** | 909 | ✅ |
| Scale +1 | 1000 | 1299.999952 | **1299** | 1299 | ✅ |
| Plate +1 | 1500 | 1949.999928 | **1949** | 1949 | ✅ |
| Plate +2 | 2000 | 2599.999905 | **2599** | 2599 | ✅ |

**四筆截圖價都剛好比 `基準價 × 1.3` 少 1。**
那不是誤差,是 **MBF 表示不出精確的 1.3**(最接近的是 `1.2999999523`),
乘出來落在整數下方一點點,BASIC 的截斷取整就少了 1。

> **判準**:**「差一點點」的偏差不要當成雜訊四捨五入掉,它可能就是主要證據。**
> 若倍率真是 1.3,四筆應該是 910/1300/1950/2600;
> 四筆**同時**少 1 的機率不是巧合,而是浮點格式的指紋。
> 一個假設能解釋「為什麼偏偏差這個量」,比能解釋「大致對得上」強一個等級。

| 倍率 | 家數 | 例 |
|---:|---:|---|
| 0.6 | 1 | Athe / The Mermaid |
| 0.7 | 1 | Woodhaven / Flickering Light |
| 0.8 | 4 | Myrquacid / Jorlor's Healers |
| 0.9 | 4 | Precious Plains / Lucky Blades |
| 1.0 | 20 | Athe / The Blacksmith |
| 1.1 | 4 | Green Hamlet / Kor's Smithy |
| 1.2 | 12 | Gleon / Flashing Steel |
| 1.25 | 1 | Arcania / Best Healing |
| 1.3 | 3 | Atlantis / Enchanted Armor |
| 1.4 | 1 | Atlantis / Healers |
| 1.5 | 3 | Gleon / Mithril Light |
| 1.7 | 3 | Terynor / Mystic Sky |
| 2.0 | 4 | Terynor / Ares' Elixer |

**遠離起點的城鎮倍率較高**(Green Hamlet 是起始村,多為 1.0–1.1;
Terynor / Atlantis / Oceana 有 1.7–2.0)。

⚠ 這個「距離 → 倍率」的關聯是**觀察,不是機制** ——
倍率是寫死在資料檔裡的常數,不是遊戲算出來的。
不要寫成「遊戲依距離加價」。

⚠ 三筆記錄(`Gleon / BladeMaster`、`Myrquacid / Volir's Academy`、
`Spider Bay / Balik's Arena`)在位移 38 是 `40 00 00 00`,**不是合法 MBF**
(指數位元組為 0 = 零值)。那三家的性質未解 ——
名字看起來分別是訓練所 / 學院 / 競技場,可能根本不賣東西。**未解,不臆測。**

## 5. 手冊 p.30 的護甲價格是什麼

不是 DOS 版的值。§2 已證明 DOS 版的資料檔與 DOS 版的截圖自洽,
所以差異落在手冊那一側 —— 與 [`125`](125-manual-confirms-spells.md) §1
的發現一致:**手冊內文是從 Apple II 版翻譯的**(p.4 還寫著「APPLE Ⅱ 64K」)。

**信心等級:證據充分**(不是已確認 —— 沒有 Apple II 版的資料檔可以直接對)。

## 6. 對 remake 的影響

`docs/formats/04` 的「欄 3 = 價格」要改寫成「欄 3 = **基準價**」,
並補上商店倍率這一層。**這會影響經濟平衡** ——
照舊寫法實作,所有商店都會賣同一個價,玩家跑遠路買貴貨的設計就消失了。
