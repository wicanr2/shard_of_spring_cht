| # | 結果 | 信心 |

支撐集猜對了(4–12),**分佈形狀猜錯了**。

## 1. 位址

`CHARUTIL.EXE` 有兩處,形狀完全一致(創造時擲一次、重擲時再擲一次):

```
010ABA  INT 3D:34            ; RND
010ABD  mov di, 6C2Ah
010AC0  INT 3F:91            ; × A
010AC3  INT 3F:71            ; 存進暫存
010AC7  INT 3D:34            ; RND(第二次)
010ACA  INT 3F:91            ; × A   ← di 沒有重新載入,還是 6C2A
010ACD  INT 3F:85            ; 加
010AD1  mov di, 6C2Eh
010AD4  INT 3F:81            ; + B
010AD7  mov bx, 1Ah
010ADA  INT 3D:03            ; INT() —— 只有這一次
010ADD  INT 3F:77            ; → 整數
010AE4  mov [di+6A86h], bx   ; 寫進屬性陣列
```

另一處在 `0x10CF7`(重擲那一條路),指令序列逐條相同。

⚠ **兩次乘法用同一個 `di`。** 第二次 `INT 3F:91` 之前沒有 `mov di`,
所以兩顆「骰子」的範圍相同 —— 這一點決定了它是對稱三角分佈。

⚠ **`INT()` 只出現一次,在總和之後。**
`INT(x + y + B)` 與 `INT(x) + INT(y) + B` 不是同一個分佈,
而兩者的支撐集幾乎一樣 —— **只看範圍分不開**。

## 2. 為什麼 [`143`](143-character-creation.md) 找不到

`143` §5 掃的是 `INT 3D:03`,兩處的面數都寫成「`mov bx, 1Ah`(26)」,
於是判定「擲屬性那一段不在這兩處」。

**那個 26 不存在**:`0x1A` 是浮點累加器的**位址**,而 `3D:03` 是 `INT()` 不是亂數
([`152`](152-experience-settlement-formula.md) §3)。真正的亂數是 `3D:34`,
而 `143` §5 自己就寫著「要嘛走另一個亂數入口(`3D:34`)」—— **那個猜測是對的**。

> **判準**:一個「排除某處」的結論,若它的依據是**某個常數的值**,
> 那麼常數被推翻時,排除也跟著作廢。
> 這裡連鎖了三篇:`77` 讀錯 `1Ah` → `143` 據此排除兩個位址 →
> `152` 訂正 `1Ah` → 排除失效,回頭一掃就找到了。

## 3. `A` 與 `B` 能被 15 個樣本約束到什麼程度

[`143`](143-character-creation.md) §5 的 15 個擲出值:最小 **4**、最大 **12**、平均 **8.4**。

對 `INT(RND×A + RND×A + B)`:

```
支撐集 = B … ⌈2A + B⌉ − 1
期望值 = A + B − 0.5      (兩個 U[0,A) 的和期望 A,取整平均少 0.5)
```

| 約束 | 推得 |
|---|---|
| 最小值 4 | `B = 4`(支撐集的下界就是 `B`)|
| 平均 8.4 | `A ≈ 4.9` |
| 最大值 12 出現過 | `2A + B > 12` → `A > 4` |

**最貼的整數解是 `A = 5`、`B = 4`** → 支撐集 4…13、平均 8.5。
支撐集比觀察到的多一個 13,而 `P(13) = 2%`,15 個樣本一次都沒抽到的機率 **74%** ——
不衝突。

⚠ **這仍然是假設。** `A = 4.5、B = 4`(支撐集剛好 4…12)同樣通過所有檢定,
15 個樣本分不開。引擎用 `A = 5、B = 4` 並標成具名假設。

⚠ 但**形狀不再是假設**:三角分佈是讀出來的。
先前的 `4d3` 是四顆骰的和,峰度明顯更高 ——
**支撐集相同而分佈不同,玩起來只覺得「極端值比較少」**,不會有人發現。
