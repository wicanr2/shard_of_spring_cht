## 1. `CMBT` 的挑選迴圈

`CMBT.EXE` `0x11139`–`0x1117D`:

```
011139  INT 3D:34  RND
01113E  di = 945Ch / INT 3F:91 乘      ; RND × 候選數
011147  bx = 1Ah / INT 3D:03           ; INT()
011154  ds:9458 ← 隨機索引
011161  bx = 943Ch / INT 3F:C4         ; 取陣列元素 → ax
011169  sub ax, ds:3656h               ; ★ 減區域編號
01116D  and ax, ax
01116F  jge +2
011171  neg ax                         ; ★ 取絕對值
011173  cmp ax, 1
011176  jg  01113A                     ; ★ 差 > 1 → 重擲
011178  INT 3F:C4 → ds:945A            ; 收下
```

`neg` 那一條是**逐位元組讀到的**(`F7 D8`),不是猜的 —— 所以判定是
**絕對值** `|值 − 區域| ≤ 1`,不是單邊的「不超過」。

⚠ 第 3 項標**證據充分**不是已確認:沒有讀到 `ds:943C` 那個陣列**從哪裡填**。
支持它的是三件事 —— 值域對得上(區域用到 1、2、3、5、6、8、9,
而欄 9 是 1–10、13)、語意對得上(難度階級,[`90`](90-monster-column-9-is-a-tier.md))、
效果對得上(起始區是 1、最後一座地城是 9)。**要定案得讀那個陣列的填入端。**

## 2. 世界地圖:三區

`WRLDMOVE.EXE` `0x10E42`–`0x10E7D`:

```
010E42  cmp ds:3518h(東西 x), 70   → bx = TRUE 當 x > 70
010E4D  cmp ds:351Ah(南北 y), 60   → dx = TRUE 當 y ≤ 60
010E5C  兩者皆真 → ds:3656 = 3
010E6A  否則 y > 60 → ds:3656 = 6
010E7D  否則        → ds:3656 = 1
```

座標欄位出自 [`149`](149-every-action-costs-one-tick.md) §2
(`GROUPS.DAT` 位移 35 = 東西、37 = 南北)。

| 區域 | 範圍 | 遭遇的難度階級 |
|---:|---|---|
| **1** | x ≤ 70 且 y ≤ 60(西北,起始區)| 1–2 |
| **3** | x > 70 且 y ≤ 60(東北)| 2–4 |
| **6** | y > 60(南方)| 5–7 |

### 2.1 順帶:世界地圖上的兩段固定敘述

同一支模組在 `(x=70, y=57)` 依朝向印兩段字(`0x10C86`–`0x10CE3`):

| 朝向 | 文字 |
|---|---|
| 3(南)| Before you is an archway set into a stone gate. … Large Gothic letters carved over the archway read, **'ISLANDA'** |
| 1(北)| **Thank you for visiting Islandia. Good Hunting.** |

**那道拱門就在 `x = 70` 的分區線上** —— 走過去等於換一個遭遇區。
⚠ 另有一處 `(x=86, y=35)` 的特判(`0x10C17`),**未讀**。

## 3. 迷宮:逐座指定

`MAZEMOVE.EXE` `0x1128C`–`0x1132E`,依 `ds:3534`(當前迷宮編號):

```
預設                    ds:3656 = 6
迷宮 1 或 2             → 1
迷宮 3 或 6             → 3
迷宮 4                  → 5
迷宮 5   樓層 x < 25 且 y < 25 → 2
         否則                  → 8
迷宮 12                 → 9
```

**DG5 按樓層座標再分兩區**:西北角是 2,其餘是 8 —— 塔的深處明顯更難。
樓層座標欄位出自 [`114`](114-maze-coordinates.md)(`GROUPS.DAT` 位移 79/81)。

⚠ 沒有列到的迷宮(7–11、13)走**預設值 6**。這是讀到的(那一行在鏈的最前面,
之後的比較只覆寫命中的),不是漏掉。

## 4. `ds:3534` = 當前迷宮編號

上面那條鏈把 `ds:3534` 與迷宮編號 1–12 比。而 [`166`](166-camp-hunt-identify-print.md) §2
讀到 `H)unt` 的第一道閘門是 `ds:3534 < 99 → 'You're inside!'`,
當時只能從訊息**推**它是「在室內」。

現在兩邊對起來:**`ds:3534` 是當前迷宮編號,`99` 是「不在任何迷宮」的哨兵** ——
與背包空格用同一個哨兵值。所以「只能在野外打獵」是這個變數的直接後果。

> **判準**:一個變數在 A 模組只看得到「與 99 比」,在 B 模組看得到
> 「與 1…12 比」——**兩邊合起來才有語意**。單看任一邊都只能推。

## 5. 對實作的意義

引擎目前是「亂數挑一隻」並註明「遭遇表未解」。現在可以照抄:

1. 依所在位置算出區域編號;
2. 隨機挑一隻怪物,`|欄9 − 區域| > 1` 就重挑。

⚠ **重擲沒有次數上限** —— 原版是無條件 `jg` 回頭。若某個區域沒有任何
階級落在 `±1` 內,原版會**當掉**。引擎要加上限並在耗盡時明講,
⛔ 但**不要**用「取最接近的一隻」悄悄代替 —— 那會讓一個原版不存在的怪物出現。
