## 1. 三段管線

```
0x14F26  cmp 欄3[法術], 1
0x14F2B  jg  0x14F30      ; 類別 ≥ 2 → 先選目標(掃單位的欄0/欄1)
0x14F2D  jmp 0x1505A      ; 類別 1   → 跳過選目標

0x1505A  ── 共同段 ──
0x1505A  INT(RND × ds:977E) + 1     ; d100(docs/re/154)→ ds:9A46
0x15087  ax = 欄4[法術]              ; 每點威力
0x15096  bx = 欄5[法術]              ; 每一級的法力單價
0x150A7  INT 3F:8D 除                ; 欄4 ÷ 欄5
0x150B6  ds:9A48 ← INT(商)           ; 像是**等級**

0x150BB  bx = 欄3[法術]
0x150BF  INT 3F:5E + 內嵌 13 項表     ; ★ 依效果類別分派
```

**選目標那一段是「類別 ≥ 2 才走」的前置,不是分岔** ——
兩條路都會到 `0x1505A`。這一點很重要:先前
[`172`](172-spells-column-arrays.md) §3 把它讀成「類別 1 走另一條路」,
而實際上它只是**跳過選目標**。

⚠ `欄4 ÷ 欄5` 與 d100 **怎麼合成傷害仍然沒讀到** —— 那在各類別自己的處理裡。

## 2. `INT 3F:5E`:帶內嵌表的分派

`0x150BF` 之後的 27 個位元組不是指令,是資料:

```
0D                                   ; 項數 = 13
F4 58  B9 5E  A7 5F  A7 5F  A7 5F    ; 13 個 word(段內位移)
A7 5F  A7 5F  3B 4A  48 64  11 67
67 65  3B 4A  3B 4A
```

`0x150C4 + 1 + 26 = 0x150DF`,而下一條指令(`E9 6D D3`,`jmp`)正好在那裡
—— **長度對得起來**,所以「計數位元組 + N 個 word」的形狀是對的。

**13 正好是效果類別的個數**([`formats/04`](../formats/04-spells-items-dat.md):1–13),
而且分組也對得上已經讀過的東西:

| 類別 | 段內位移 | 備註 |
|---:|---|---|
| 1 | `0x58F4` | 群體傷害 |
| 2 | `0x5EB9` | 單體重擊 |
| **3–7** | **`0x5FA7`(五項相同)** | 屬性增減 + 防護 —— 對得上 `0x160A2` 那條 `ds:9B32` 鏈 |
| 8 / 12 / 13 | `0x4A3B`(三項相同)| 復活 / 非戰鬥 / `TRANSFERENCE` |
| 9 | `0x6448` | 解毒 |
| 10 | `0x6711` | 解除束縛 |
| 11 | `0x6567` | 束縛 |

**類別 3–7 共用一個目標**,而 [`171`](171-spell-effect-class-table.md) §3 讀到的
`ds:9B32` 鏈正是「進去之後再依類別分欄號」—— 兩者接得上。

## 3. ⚠ 表的解析沒有完全驗證

把位移當成 `linear = 位移 + 0xFE00` 去看落點:

| 類別 | 落點 | 開頭位元組 | 判斷 |
|---:|---|---|---|
| 2 | `0x15CB9` | `0E E8 93 2A` = `push cs; call` | **乾淨的指令起點** ✓ |
| 3–7 | `0x15DA7` | `BB 60 9B CD 3F 6E` = `mov bx, 9B60h; INT 3F:6E` | **乾淨** ✓ |
| 8/12/13 | `0x1483B` | `90 8B D9` = `nop; mov bx, cx` | 可能(BASIC 常留 `90`)|
| 1 | `0x156F4` | `00 75 01 4A` | ✗ 落在指令中間 |
| 9 | `0x16248` | `3F 6E 90 90` | ✗ 落在 `INT 3F:6E` 的第 2 個位元組 |
| 11 | `0x16367` | `A2 93 23 DB` | ✗ 落在指令中間 |

**三項乾淨、三項不乾淨。** 所以基底 `0xFE00` 對其中一部分成立,
對另一部分不成立 —— 可能是這張表的項目不是純 word,
或者不同項用不同的基底。

⛔ **不要拿這張表的位址去讀程式碼**,除非先解決這一點。
可以用的是**結構**(13 項、3–7 共用、8/12/13 共用),那部分由
「項數 = 類別數」與「分組對得上已讀的 `ds:9B32` 鏈」兩件事支持。

> **判準**:一張推出來的跳表要**逐項檢查落點是不是指令起點**。
> 這裡六項裡有三項不是,而如果只抽驗到乾淨的那幾項,
> 就會拿著一半錯的位址往下挖。
