# 190 — `ITEMS.DAT` 欄6 是**道具損壞率**,不是發動成功率

> 輸入:`CMBT.EXE` / `CAMP.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 兩支都先跑過 `tools/ida/unlock_module.py`。
> 信心:**已確認**(兩個模組各讀到一次,且資料面獨立印證)。

推翻 [`157`](157-magic-item-rate-is-a-percentage.md) 的**標籤**。
那一篇把判定式讀對了(`擲骰(100) ≤ 欄6`),但**把那一支做的事讀錯了** ——
它不是「發動」,是**把道具弄壞**。

## 1. `CMBT`:旗標的消費端印的是 `Item Breaks !`

`157` 停在 `0x17C97` 的比較。往下再走三行就看得到它只是**設一個旗標**:

```
017C92  mov  bx, [di+7780h]      ; ITEMS 欄6
017C96  inc  bx
017C97  cmp  ax, bx
017C99  jl   0x17C9E             ; 擲骰 ≤ 欄6
017C9E  mov  word ptr ds:930Ch, 1
017CA7  mov  word ptr ds:930Ch, 0
```

`ds:930C` 的六個存取點(`tools/ida/find_dsref.py`,掃 16,416 條指令)裡,
唯一的**讀取**在 `0x11F4D`:

```
011F4D  mov  bx, ds:930Ch
011F51  and  bx, bx
011F53  jnz  0x11F58             ; 旗標為真 →
011F55  jmp  0x11FE3             ; 為假 → 跳過
…       (把背包那一格清掉)
011FBF  mov  bx, 94DAh           ; ds:94DA = 'Item Breaks !'
011FC2  INT  3F:6E               ; 印
```

**旗標為真 = 道具壞掉並從背包移除。**

> **判準**:讀到「比較 → 設旗標」時,**結論在消費端不在比較處**。
> `157` 只讀到比較就下了語意,而那個語意「看起來合理」——
> 魔法道具有成功率是這類遊戲的常識,所以沒有任何訊號說它錯了。

## 2. `CAMP`:同一個欄位、同一個形狀、同樣接到 `Item Breaks !`

`0x11E4B`–`0x11EB2`:

```
INT 3D:34 / ×ds:72CA(100) / INT() / +ds:72CE(1)   → d100
mov bx, ds:7622h                                   ; ← 欄6
INT 3F:57 → 浮點 / INT 3F:A5 比較
jbe 0x11E74                                        ; **≤ → 壞掉**
…(清掉背包那一格)…
011EB2  call sub_12B11                             ; 印 'Item Breaks !'
```

`ds:7622` 的來源在 `0x11C5F`:`mov ax, [di+6E3Ah]`。
而 `6E3A` 是 `ITEMS.DAT` 的**第六個欄位**陣列 —— 載入迴圈 `0x12EDC`–`0x12F2C`
依序 `INPUT#` 六個欄位:

| 陣列 | 步長 | 欄 |
|---|---:|---|
| `6B1C` | 4 | 名稱(字串描述子)|
| `6C00` | 4 | 小寫名 |
| `6CE4` | 2 | 基準價 |
| `6D56` | 2 | 欄4 |
| `6DC8` | 2 | 欄5 |
| **`6E3A`** | 2 | **欄6** |

迴圈上界 `cmp ax, 38h` = 56 → 57 筆,與 `ITEMS.DAT` 的筆數相符。

## 3. 資料面的獨立印證:火把 100、鑰匙 0

| 道具 | 欄6 | 當成「發動率」讀 | 當成「損壞率」讀 |
|---|---:|---|---|
| 火把、油燈 | **100** | 必定發動 | **一用就沒了** ✅ |
| 鑰匙 / 銅銀金鑰匙 / 王家印璽 | **0** | **永遠發動不了** ❌ | **永遠不壞** ✅ |
| 戒指、法杖、權杖 | 7–15 | 七到十五次才成功一次 ❌ | 每次用有一成左右壞掉 ✅ |
| 傳送器 | 50 | 一半機率沒反應 | 用兩次壞一次 ✅ |

**鑰匙那一列決定性**:鑰匙是解謎道具,欄6 = 0 讀成「發動率」等於它永遠打不開門。
火把「一用就沒了」也正是耗材該有的行為。

## 4. 對實作的影響

引擎的 `magic.ItemTriggers(編號, 欄6, r)` 把欄6 當**發動率** —— 反了。
正確的形狀是:

```
用魔法道具 → 法術**照樣發動**
           → 另擲 d100,≤ 欄6 → 道具損壞,從背包移除
```

⚠ 這個錯誤**沒有症狀**:戒指有時有效有時沒效,在一款 1986 年的 RPG 裡
看起來完全正常。抓到它的是 F3 對字串 —— `Item Breaks !` 這句話在引擎裡
沒有任何對應,而去找它的呼叫端才翻出旗標的真正語意。
