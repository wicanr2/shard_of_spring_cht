# 191 — 攻擊附帶中毒:武器 62、15%、只中正常狀態的隊員

> 輸入:`CMBT.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`([`186`](186-monster-ai-target-placement-cast.md) §0)。
> 信心:**已確認**(位址逐條讀出;常數走 DGROUP 初始資料串;資料面獨立印證)。

補上 [`153`](153-damage-formula-closed.md) 沒讀到的那一段 —— 傷害套用之後、
死亡判定之前還有一支中毒判定,而引擎的 `Attack()` 到這一篇為止只算傷害。

## 1. 傷害套用之後的三段(`0x13A07`–`0x13B35`)

```
013A07  di = ds:93A4(防禦者) + 2Dh      ; 45 = 15 × 3 → 屬性 3(生命值)
013A14  sub [di+6822h], ds:9786         ; 扣傷害
013A18  cmp …, 1 / jl → [di+6822h] = 0  ; 低於 1 就夾到 0
013A28  bx = 防禦者索引
013A33  cmp 生命值, 0 / jg → 0x13A3D    ; 還活著 → 往下
        否則                → 0x13B36    ; **死了 → 跳過中毒**,走死亡分支
013A3D  cmp bx, 8 / jg → 0x13A45        ; **索引 > 8 才往下**
        否則                → 0x13B35    ; 直接返回
```

`cmp bx, 8` 那一行是整段的關鍵:單位陣列 **0–8 是怪物、9–13 是隊員**
([`spec/07`](../spec/07-combat-scene.md) §1),所以 `> 8` = **防禦者是隊員**。

**中毒只發生在隊員身上。** 隊員打中毒蛇不會讓蛇中毒 —— 那條分支根本不執行。

`0x13A45`–`0x13A8A` 是側欄重繪(`bx − 7` 當行號、先印 `ds:97E2` 的五個空白
再印生命值),依 [`CLAUDE.md`](../../CLAUDE.md) §1.2 屬顯示層,不往下追。

## 2. 三個條件同時成立才中毒(`0x13A8D`–`0x13AD0`)

```
013A8D  di = ds:93A6(攻擊者) + 3Ch      ; 60 = 15 × 4 → 屬性 4(武器編號)
013A96  cmp word ptr [di+6822h], 3Eh    ; **62**
013A9B  bx = (相等) ? −1 : 0

013AA1  INT 3D:34                       ; RND
013AA6  mov di, 9802h                   ; **ds:9802 = MBF 0.15**
013AA9  INT 3F:A1                       ; 比較
013AAE  [bp-8] = bx                     ; 存武器那一項
013AB1  bx = (below) ? −1 : 0            ; **RND < 0.15**
013AB7  and bx, [bp-8]

013ABA  dx = 防禦者索引 + 78h            ; 120 = 15 × 8 → 屬性 8(狀態)
013AC1  cmp word ptr [di+6822h], 0
013AC6  dx = (相等) ? −1 : 0             ; **狀態 == 0(正常)**
013ACC  and dx, bx / and dx, dx
013AD0  jnz → 0x13AD5                    ; 三項全成立
        否則 → 0x13B35(返回)
```

`ds:9802` 的初值由 `python3 tools/dgroup_init.py CMBT.EXE --at 9802` 讀出:
`9a 99 19 7e` = MBF **0.15**。

## 3. 效果(`0x13AD5`–`0x13B34`)

```
013AD5  LOCATE 13h, 17h
013AEA  印 ds:97EC = 'and is poisoned!'
013AF7  mov word ptr [di+6822h], 1       ; **屬性 8(狀態)= 1**
013B11  印 ds:9806 = 'P'                 ; 側欄的狀態字母
```

狀態 1 = 中毒,與 [`formats/03`](../formats/03-monsters-dat.md)
「`SPELLS.DAT` 欄2(系別)命中時直接寫進狀態欄」是同一組編號。

⚠ **訊息與狀態的順序**:先印再寫。對 remake 沒有差別,記著是因為
下一行的 `[di+6822h]` 用的仍是 `0x13ABD` 算好的 `di`(狀態格),不是生命值那一格 ——
讀成「把生命值設成 1」會是一個自洽而錯的結論。

## 4. 資料面的獨立印證:62 是孤島

`MONSTERS.DAT` 欄5(武器編號)在 74 筆裡的分佈:

| 欄5 | 筆數 |
|---:|---:|
| 0–13 | 69 |
| **62** | **5** |

那五筆是 **Cobra(10)、Death Adder(13)、Ghoul(24)、Pit Viper(59)、
Rattlesnake(60)** —— 四條毒蛇加一隻食屍鬼,其餘怪物一筆都沒有用到 62。

62 與最接近的 13 之間整整空了 48 個編號,**它不是武器表上的一格,是一個哨兵值**。
這一項獨立於反組譯:就算把 `0x13A96` 的比較讀錯,資料本身也只能是這個意思。

⚠ 反過來說,**隊員永遠不可能觸發中毒** —— 條件是攻擊者屬性 4 == 62,
而角色的屬性 4 來自裝備欄,`ITEMS.DAT` 只有 57 筆(編號 0–56),取不到 62。
與 §1 的「只有隊員會中毒」兩邊夾起來,這一支就是**怪物咬人**專用的。
