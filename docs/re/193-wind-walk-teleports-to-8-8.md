# 193 — `WIND WALK`(風行術)把全隊傳送到世界座標 (8, 8)

> 輸入:`CAMP.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))、`SPELLS.DAT`、
> `TOWNDATA.BIN`。反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(判斷式、兩個欄位寫入、模組轉交都逐行讀出;資料面兩重印證)。

關掉 `translations/module-text/CAMP.tsv` 第 109 列
(`A roaring blast of wind buffets the party…`)的「是哪一個法術沒讀到」,
並把 `magic.EffUtility`(效果類別 12)三個成員裡的第一個從佔位變成實作。

## 1. 觸發:`ds:7430 == 22`

```
012419  cmp word ptr ds:7430h, 16h    ; **22**
01241E  jz  → 0x12423                  ; 是 → 風行術
012420  jmp → 0x124B6                  ; 否 → 下一個類別 12 的法術
```

`ds:7430` 是**選中的法術在 `SPELLS.DAT` 的列號**。查名字的迴圈
(`0x11726`–`0x1174E`)比對輸入與法術名,對上就 `mov ds:7430h, dx`;
接著 `0x1177A` 拿它當索引取三個平行陣列:

| 基底 | 步長 | 欄 |
|---|---:|---|
| `69B4` | 2 | 欄2(系別)|
| `69FC` | 2 | 欄3(效果類別)|
| `6A44` | 2 | 欄4(威力)|
| `6A8C` | 4 | 字串 |

相鄰基底相距 72 = 2 × 36 → `DIM` 36 格,而 `SPELLS.DAT` 有 34 列。

**第 22 列 = `WIND WALK`。**

## 2. 效果:兩個座標欄位寫 8,然後轉交 `WRLDMOVE`

`0x12423`–`0x124B3`:

```
012423  ds:66C4 = ds:34DC              ; 隊伍記錄(GROUPS.DAT)
01242C  ds:66C8 = 8   ; ds:66CA = 25h  ; **值 8 → 位移 37**
012438  call loc_10043                 ; MID$ 寫回(re/120 的同一支)
01243D  ds:34DC = 結果

012443  ds:66C4 = ds:34DC
01244B  ds:66C8 = 8   ; ds:66CA = 23h  ; **值 8 → 位移 35**
012457  call loc_10043
01245C  ds:34DC = 結果

012462  ds:352E = "N"                  ; 一個字元變數(§5)
01246B  訊息框(ds:7806 = 'A roaring blast of wind…')

012492  ds:351A = 8                    ; 世界座標 y(記憶體副本)
012498  ds:3518 = 8                    ; 世界座標 x
01249E  ds:3798 = 'CAMP'               ; 來源模組
0124A7  ds:37A0 = 'WRLDMOVE'           ; **目標模組**
0124B3  jmp → 轉交
```

`GROUPS.DAT` **位移 35 = 世界東西、37 = 世界南北**
([`formats/02`](../formats/02-groups-dat.md)、[`149`](149-every-action-costs-one-tick.md) §2),
而 `ds:3518` / `ds:351A` 是同兩個值的記憶體副本
([`43`](43-common-block-and-array-indexing.md) §4 的訂正)。
**記錄與記憶體兩份都寫**,所以離開營地之後不論走哪一條路都是 (8, 8)。

`loc_10043` 是 `MID$` 的寫回形式(引數:記錄 `ds:66C4`、值 `ds:66C8`、
位移 `ds:66CA`),與 [`120`](120-offset-84-cleared-in-camp.md) §1 是同一支。

## 3. (8, 8) 是哪裡:翠綠村的西邊一格

`TOWNDATA` 的 13 個城鎮座標([`53`](53-world-tiles-towns-and-draw-renderer.md))第一筆是
**(9, 8) = 翠綠村(Green Hamlet)**,也就是遊戲的起點城鎮。

**風行術把隊伍丟在它西邊一格。** 落在城鎮**旁邊**而不是城鎮**上面** ——
踩上城鎮格會直接進城,而這個法術要做的是「回到文明世界」不是「進城」。

## 4. 資料面第二重印證:欄6 就寫著

`SPELLS.DAT` 第 22 列的欄6(命中訊息)是 **`Whole party is teleported`**。

| 來源 | 說的是 |
|---|---|
| 反組譯 | 寫兩個世界座標欄位、轉交 `WRLDMOVE` |
| `SPELLS.DAT` 欄6 | 「全隊被瞬間移動」 |
| 法術名 | `WIND WALK` |
| CAMP:109 | 「一陣怒吼般的狂風吹襲隊伍,當聲響平息之後……」 |

四個各自獨立的來源指向同一件事。

⚠ **欄6 一直都在譯文清冊裡。** 「是哪一個法術沒讀到」這個問題,
在動反組譯之前先掃一遍 `SPELLS.DAT` 的命中訊息就會收斂到剩三個候選
(類別 12 只有風行術、魔法火炬、水晶燈術)。
與 [`187`](187-shop-purchase-recipient.md) 的教訓同一條:**先看手上的資料**。
