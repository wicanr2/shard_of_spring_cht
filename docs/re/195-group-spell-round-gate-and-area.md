# 195 — 群體傷害法術:第一回合放不出來、作用範圍是 5×5

> 輸入:`CMBT.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(兩個條件、範圍的兩軸邊界都逐行讀出)。

關掉 `translations/module-text/CMBT.tsv` 第 97–100 與 124/125 兩組,
以及 [`spec/09`](../spec/09-magic-items.md) §3 的「法術作用範圍未解」。

## 1. 第一回合放不出群體傷害(`0x14B92`)

```
014B92  di = ds:98D8 × 2               ; 選中的法術索引
014B98  cmp word ptr [di+7340h], 1     ; **欄3(效果類別)== 1(群體傷害)**
014B9D  bx = (相等) ? −1 : 0
014BA3  cmp word ptr ds:9314h, 1       ; **回合 == 1**
014BA8  dx = (相等) ? −1 : 0
014BAE  and dx, bx
014BB2  jnz → 0x14BB7                  ; 兩項都成立 → 印
        否則 → 0x14C81(照常施放)
014BB7  LOCATE 0Dh,17h → 'You will not be  '
        LOCATE 0Eh,…  → 'prepared for that'
014BF6  ds:9964            → 'spell until the  '
                           → 'next round.'
```

兩個常數的來源不必再追:

- `ds:7340 + 2i` = `SPELLS.DAT` **欄3(效果類別)**
  ([`172`](172-spells-column-arrays.md) §2 的五個陣列接縫一個不差)
- `ds:9314` **只有兩處寫**:`0x10457` 初始化成 0、`0x11EAC` 每回合 `inc`。
  同一個變數在 `0x1249F` 被拿去比 2,而那正是
  [`186`](186-monster-ai-target-placement-cast.md) §3 讀出來的
  「怪物在第 2 回合必定施法」—— **兩篇對同一個變數的判讀一致**。

**規則:效果類別 1 的法術在第 1 回合施放不出來,要等第 2 回合。**

⚠ 這不是「失敗」也不是「浪費法力」—— 那一段在扣點數之前就把玩家擋回去。

## 2. 作用範圍 = 以游標為中心的 5×5(`0x15A0B`)

```
0159C2  雙重迴圈 1…5 × 1…5,每格 x = 17i + 30、y 依 ds:9B26  ; 畫出範圍框
015A0B  ds:9B2A = −2                   ; 「沒找到」哨兵
015A11  ax = ds:9346(游標 x)
015A19  ds:9B2C = ax + 2               ; **x 上界**
015A1C  bx = ax − 2                    ; **x 下界**
015A24  ax = ds:9348(游標 y)          ; 同樣 ±2 → ds:9B2E / ds:93B0
        …掃描…
015D66  cmp word ptr ds:9B2Ah, 0FFFEh  ; **仍然是 −2 = 一個單位都沒掃到**
015D6B  jz → 0x15D70                   ; → 'NO ONE IN' / 'TARGET AREA'
```

兩軸各 ±2 → **5 × 5**,而前面那個 `1…5 × 1…5` 的繪圖迴圈畫的就是同一塊
(每格 17 像素 = 一個圖塊寬)。**範圍框與判定範圍同一塊**,
不是畫一塊算另一塊。

**規則:群體傷害以游標為中心的 5×5 判定;裡面一個單位都沒有 → 印
「目標區域內沒有人!」,不施放。**

⚠ 先前引擎對類別 1 是**打敵方全部**([`172`](172-spells-column-arrays.md) §3 只讀到
「類別 1 跳過選目標」,就落回了全體)。**「不選目標」不等於「打全部」** ——
它跳過的是「指定一個單位」,游標本身仍然決定範圍。
