# 197 — `DAZA REVELI`:通關咒語打在施法提示上,開的是 `GROUPS.DAT` 位移 65

> 輸入:`CAMP.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(判斷式、寫入位移、三句訊息的分支都逐行讀出)。

關掉 `translations/module-text/CAMP.tsv` 第 78/79/80 列,
並補上 `GROUPS.DAT` **位移 65** 的語意([`formats/02`](../formats/02-groups-dat.md)
先前沒有這一列)。

## 1. 咒語輸入的是「要施放哪個法術?」那一格

`0x11694`–`0x116B4`:

```
011694  ds:680A = −1
01169A  call sub_101E2          ; 讀一行輸入 → ds:3794
0116A9  與空字串比 / jnz → 繼續 ; 空白 → 離開
```

**沒有另外的輸入框。** 玩家在營地按 `C)ast spell`,
在「`Cast what spell?`」那裡把咒語當成法術名打進去。

## 2. 兩個條件:字串相符 且 在第 5 座地城

```
0116B7  ds:3794 與 ds:740E = 'DAZA REVELI' 比
0116C0  dx = (相等) ? −1 : 0
0116C6  cmp ds:3534h, 5              ; **當前迷宮編號 == 5**
0116CB  bx = (相等) ? −1 : 0
0116D1  and bx, dx / jnz → 0x116DA   ; 兩項都成立
        否則 → 0x1171F(當成法術名去查表)
```

`ds:3534` = **當前迷宮編號**,`99` = 不在迷宮
([`169`](169-encounter-zone-selects-the-monster.md) §1 表列 6,已確認)。

**在別的地方唸這句咒語沒有用**,它會掉進法術查表那一支,
然後因為沒有這個法術而印 `Mumble, mumble, what spell did you say ?`。

## 3. 效果:`GROUPS.DAT` 位移 65 ← 1

```
0116DA  LOCATE 17h … 印 ds:741E = 'The gate opens'
0116EF  ds:66C4 = ds:34DC            ; 隊伍記錄
0116F8  ds:66C8 = 1                  ; 值
0116FE  ds:66CA = 41h                ; **位移 65**
011704  call loc_10043               ; MID$ 寫回(re/120 的同一支)
01170F  訊息框
01171E  retn
```

**位移 65 = 大門已開啟的旗標。** 它與位移 63(治療池已使用次數,
[`155`](155-gem-puzzle-and-healing-pool.md) §2.1)相鄰,兩個都是**地城的一次性進度**。

⚠ 旗標存在隊伍記錄裡 → **跨存檔留著**,不是只在這一趟有效。

## 4. 打錯就 `Mumble`

`0x1171F`–`0x1175F`:輸入不是咒語(或不在地城 5)時,拿它去比 33 個法術名
(`ds:68DC + 4i`,迴圈上界 33);對上就照常施法,對不上就印
`Mumble, mumble, what spell did you say ?`。

**所以那三句是同一條輸入路徑的三個出口**:咒語成功 / 是法術 / 都不是。

## 5. 對 remake 的影響:引擎的字母選單放不下這個機關

引擎的營地施法是**字母選單**(`docs/spec/19` §6.1 記過的既有偏離),
而這個機關**要求玩家自己打出字串** —— 把咒語列進選單等於把答案送給玩家,
違反 [`CLAUDE.md`](../../CLAUDE.md) §1「不從程式裡取出預存答案來自動通過檢查」。

引擎因此在施法清單上多一個**唸咒語**的自由輸入(按空白鍵進入)。
⚠ 那個按鍵是**引擎的決定**,原版沒有 —— 原版整格就是自由輸入。
咒語本身是 ASCII,不需要中文輸入法。
