# 198 — 「ISLANDA」拱門:世界座標 (70, 57) 且**朝南**

> 輸入:`WRLDMOVE.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))、`WRLDMAP.BIN`。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(三個比較逐行讀出;座標對地形做過正對照)。

關掉 `translations/module-text/WRLDMOVE.tsv` 第 18 列的「觸發位置未讀」。

## 1. 三個條件 AND 起來(`0x10C86`–`0x10CAA`)

```
010C86  cmp ds:351Ah, 39h        ; **世界 y == 57**
010C8B  bx = (相等) ? −1 : 0
010C91  cmp ds:3518h, 46h        ; **世界 x == 70**
010C96  dx = (相等) ? −1 : 0
010C9C  and dx, bx / jnz → 0x10CA5
        否則 → 0x10D15(下一項檢查)
010CA5  cmp ds:3520h, 3          ; **朝向 == 3(南)**
010CAA  jz  → 0x10CAF            ; → 印拱門敘述(ds:CDF4)
        否則 → 0x10CD9
```

`ds:3518` / `ds:351A` 是世界座標的記憶體副本
([`43`](43-common-block-and-array-indexing.md) §4 的訂正,`193` §2 也用同一組)。

`ds:3520` 是**朝向**:四個 `cmp …, 1/2/3/4` 與四個 `mov …, 1/2/3/4` 成對出現在
四個方向鍵的處理裡(`0x1042A`–`0x10AE7`),而 `GROUPS.DAT` 位移 41 的朝向
就是 `1`北 `2`東 `3`南 `4`西([`formats/02`](../formats/02-groups-dat.md))。

## 2. 朝向那一項不是裝飾

敘述寫的是「**你面前**是一座嵌在石門裡的拱門。**透過拱門**可以看見……」——
從南邊走上來的玩家背對著拱門,這時印那一段就不成立。

⚠ **少讀一個 `and` 的代價不會顯示成錯誤**:玩家只會覺得敘述出現得有點多。

## 3. 地形的正對照

`WRLDMAP.BIN` 索引 `y × 121 + x`([`54`](54-f-closure.md)):

| 座標 | 圖塊 |
|---|---:|
| (69, 57) | 15 |
| **(70, 57)** | **1** |
| (72, 57) | 11 |
| (73, 57) | 11 |

`11` 是全圖最多的一種(12,463 格裡 6,933 格),也就是**海**。
拱門那一格是陸地,而它南邊兩格就進海 —— 與敘述的
「可以看見一大片島嶼,以及蜿蜒至地平線的陸地小徑」對得上。

## 4. 這一段的鄰居

同一支常式往上一點(`0x10C47`)是**進城**的判斷(圖塊 30–32 且另一個旗標),
往下(`0x10D15`)還有別的定點檢查 —— 形狀上是一串
「站在哪裡會發生什麼」的定點事件,而拱門是其中一個。

⚠ **那一串裡的其他項目沒有讀。** 引擎目前只接了拱門這一個。
