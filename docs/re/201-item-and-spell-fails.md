# 201 — `Item Fails` / `Spell Fails`:同一個判定,兩句話

> 輸入:`CMBT.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(判定式、三個進入點、挑句子的旗標都逐行讀出)。

關掉 [`190`](190-items-col6-is-break-chance.md) §5 的第一個未解項
(「`Item Fails` 與 `Spell Fails` 的條件」),並接線 `CMBT:140`。

## 1. 條件:效力 < d100

**三個**進入點,判定式一模一樣(`0x15ED6` / `0x16465` / `0x16742` 附近):

```
015ED6  ax = ds:9A48h
015ED9  cmp ax, ds:9A46h
015EDD  jge → 繼續(成功)
015EDF  jmp → 0x1692A(失敗)
```

兩個運算元都在 `0x1505A`–`0x150B6` 算好:

```
01505A  INT 3D:34            ; RND
01505F  di = 977Eh           ; ds:977E = 100(d100,re/154)
015062  INT 3F:91            ; ×
015067  INT 3D:03            ; INT()
01506F  di = 9464h(1.0) / INT 3F:81
015077  INT 3F:77
01507E  ds:9A46 = 擲骰       ; **d100,值域 1…100**

015081  di = ds:98D8 × 2     ; 選中的法術索引
015087  ax = [di+7384h]      ; **欄4(威力)**
01508B  imul ds:93A2h        ; × 投入的點數
015091  INT 3F:57            ; → 浮點
015096  bx = [di+73C8h]      ; **欄5(法力單價)**
01509A  INT 3F:71 內嵌 81    ; 變數81 ← FAC
0150A0  INT 3F:57            ; FAC ← 欄5
0150A7  INT 3F:8D 內嵌 81    ; 除:變數81 ÷ FAC
0150AF  INT 3F:77            ; → 整數(**四捨五入**,沒配 INT(),re/185)
0150B6  ds:9A48 = 效力       ; **round(欄4 × 投入 ÷ 欄5)**
```

**成功 ⟺ `round(欄4 × 投入 ÷ 欄5) ≥ d100`。**

⚠ 效力就是**成功的百分比**:投入少 → 效力低 → 大多數時候發不出來。
`CMBT:104–106`「那個法術至少需要 N 點法力」擋的是最低投入,
**這一條擋的是「投得夠不夠多」** —— 兩者不同。

⚠ **這個效力不是 `Power()`。** 引擎的 `magic.Power` 是 `欄4 × 投入`,
不除單價;發動判定另外算一份。兩個量各有用途,⛔ 不要合併。

## 2. 兩句話由 `ds:9308` 挑

失敗跳到 `0x1692A`,那一段的關鍵三行 IDA 沒切出來
(`INT 3F` 的內嵌運算元把邊界弄壞了,[`CLAUDE.md`](../../CLAUDE.md) §3.3)——
用 `tools/ida/raw_bytes.py` 直接讀位元組:

```
01694D  8b 1e 08 93   mov bx, ds:9308h
016951  23 db         and bx, bx
016953  75 03         jnz 0x16958
016955  e9 15 00      jmp 0x1696D      → 'Spell Fails'(ds:9C78)
016958  …             → 'Item Fails'(ds:9C6A)
```

**`ds:9308 ≠ 0` = 這一次是用道具 → `Item Fails`;`= 0` = 施法 → `Spell Fails`。**
`ds:9308` 在模組開場被清成 0(`0x1043C`)。

> **判準**:反組譯裡出現「一段位址沒有指令」時,不要當成資料跳過 ——
> `INT 3F` 帶內嵌運算元會讓 IDA 從那裡開始切錯,而**切不出來的那幾行
> 往往正是判斷式**。`raw_bytes.py` 存在就是為了這個。

## 3. 對 remake 的影響

`engine/internal/magic`:`EffectLevel(s, invest)` + `Fizzles(level, r)`;
戰鬥施法(`cast_scene.go`)與戰鬥用道具(`use_item.go`)各接一句。

⚠ **失敗時法力照樣扣掉** —— 原版扣點的位置沒讀到,引擎沿用既有順序,
這是具名的實作決定。

⚠ 測試 fixture 要把擲骰固定住:那件測試道具的效力只有 4,
用真亂數的話整組測試有 96% 的機率在發動那一關就被擋掉 ——
**測發動之後的行為,就要先把發動判定拿掉**。
