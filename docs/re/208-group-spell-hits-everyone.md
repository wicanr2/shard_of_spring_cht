# 208 — 群體傷害的 5×5 掃描**跑滿 14 個單位槽**:隊員也會吃到

> 輸入:`CMBT.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(掃描迴圈的上界、比對的兩個屬性、存回目標的那一行逐位元組讀出)。

關掉 [`195`](195-group-spell-round-gate-and-area.md) §3 的兩項未解 ——
worklist §8.1 C 組的第 3 項。

## 1. 逐格掃描,每格找出「站在這裡的是誰」

`0x15A0B` 起先把 5×5 的邊界算好([`195`](195-group-spell-round-gate-and-area.md) §2),
再對每一格跑一支「這一格有誰」的內層迴圈(`0x15A78`–`0x15ABB`):

```
015A6E  mov word ptr ds:9B2Ah, 0FFFFh   ; −1 = 這一格沒有人
015A74  xor ax, ax                      ; 單位索引 0
—— 迴圈 ——
015A7A  di = ax × 2
015A7E  mov bx, [di+6822h]              ; 單位 ax 的**屬性 0(x)**
015A82  cmp bx, ds:9378h                ; 與這一格的 x 比
015A86  dx = (相等) ? −1 : 0
015A8C  mov bx, ax
015A8E  add ax, 0Fh                     ; ★ +15 → 同一個單位的**屬性 1(y)**
015A93  mov cx, [di+6822h]
015A97  cmp cx, ds:93B0h                ; 與這一格的 y 比
015A9E  ax = (相等) ? −1 : 0
015AA1  and ax, dx / and ax, ax
015AA5  jnz → 015AAA
015AAA  mov ds:9B2Ah, bx                ; ★ 找到 → 存**單位索引**
—— 下一輪 ——
015AB1  ax = ds:9414 + 1 → ds:9414
015AB8  cmp ax, 0Dh                     ; ★ **13**
015ABB  jle → 015A78
```

`di = 單位 + 15 × 屬性` 是全專案共用的定址([`43`](43-common-block-and-array-indexing.md)),
所以 `+0Fh` 就是「同一個單位的下一個屬性」。比的是 **屬性 0 / 1 = 戰場座標**。

## 2. 上界 13 就是答案

單位槽的配置是**怪物 0–8、隊伍 9–13**([`spec/07`](../spec/07-combat-scene.md) §1)。
迴圈跑 `0 … 13` —— **整個陣列,沒有任何敵我判斷**。

所以:

- **範圍內的隊員會一起吃到群體傷害**
- 「目標區域內一個人都沒有」(`ds:9B2A` 停在 −2,
  [`195`](195-group-spell-round-gate-and-area.md) §2)**算隊員** ——
  只有隊員站在裡面時,法術照樣放得出去

> **判準:迴圈上界就是「這條規則管到誰」。**
> [`195`](195-group-spell-round-gate-and-area.md) §3 當時寫「`ds:9B2A` 是單一個 word,
> 看不出後續怎麼展開成受害者清單」—— 而要回答的問題其實不是「怎麼展開」,
> 是「**掃到誰**」,那個答案就在 `cmp ax, 0Dh` 那一行。
> ⚠ 問錯問題會讓一個一眼可見的答案看起來很遠。

⚠ 每一格只認**一個**單位(`ds:9B2A` 被覆寫),但戰場上一格本來就只站一個人
(`Occupant` 的前提),所以這不是限制。

## 3. 對 remake 的影響

`cast_scene.go` 的群體傷害分支拿掉 `IsMonster` 過濾。

⛔ **不要「順手」把過濾加回去**:加回去之後群體法術變成安全的,
而畫面上完全看不出規則被改過 —— 玩家只會覺得這個法術很好用。
原版讓玩家自己承擔站位的後果,那是這款遊戲的戰術深度來源之一
(3×3 陣型格、面向、先攻順序都指向同一件事)。

⚠ 引擎的增益類法術(類別 3–6 的正威力)另有一條「對自己人」的路徑,
**不受這一條影響** —— 那一條的原版選目標方式仍然未解(`cast_scene.go` 的說明)。
