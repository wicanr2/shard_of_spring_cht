# 209 — 營地的 `Spell Fails !` 與戰鬥是**同一條規則**

> 輸入:`CAMP.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(兩個呼叫端的算式逐條讀出,與 [`201`](201-item-and-spell-fails.md) 的
> `CMBT` 版本逐項比對)。

關掉 [`201`](201-item-and-spell-fails.md) §4 的第一項 —— worklist §8.1 C 組的第 4 項。

## 1. 兩個呼叫端

印訊息的那一支在 `0x12B59`(`Spell Fails !` 的字串描述子 `ds:7A26`),
`tools/ida/range_xref.py` 查到**兩處** `call`:

| 呼叫端 | 前面在算什麼 |
|---|---|
| `0x121AE` | 照明那一支(`ds:74CA` = 投入點數,[`196`](196-weapon-skill-gate-train-cost-light-spells.md) §3)|
| `0x12393` | 另一條施法路徑 |

`Item Breaks !`(`0x12B11`)只有一個呼叫端 `0x11EB2`,不在本篇範圍。

## 2. 算式與 `CMBT` 一字不差

`0x12363`–`0x12393`(第二個呼叫端,形狀較乾淨):

```
012363  ax = ds:7484        ; 欄4(威力)
012366  imul ds:74CA        ; × 投入點數
01236C  INT 3F:57           ; → 浮點
01236F  bx = ds:7486        ; 欄5(法力單價)
012373  INT 3F:71 內嵌 81   ; 變數81 ← 欄4 × 投入
012377  INT 3F:57           ; FAC ← 欄5
01237A  INT 3F:8D 內嵌 81   ; 除:變數81 ÷ FAC   ★ 效力
01237E  bx = ds:77FC        ; 擲骰
012382  INT 3F:71 內嵌 82   ; 變數82 ← 效力
012386  INT 3F:57           ; FAC ← 擲骰
012389  INT 3F:A5 內嵌 82   ; 浮點比較
01238D  jb → 012392 → call 'Spell Fails !'
```

與 [`201`](201-item-and-spell-fails.md) §1 的 `CMBT 0x15081`–`0x150B6` 對照:

| | `CMBT` | `CAMP` |
|---|---|---|
| 效力 | `欄4 × 投入 ÷ 欄5` | **相同** |
| 對手 | d100 擲骰 | 擲骰(`ds:7780` / `ds:77FC`)|
| 判定 | 效力 ≥ 擲骰 → 成功 | **相同**(比較的方向由 `ja`/`jb` 與運算元順序一起看)|
| 取整 | `3F:77` 四捨五入之後才比 | **沒有取整**,直接浮點比 |

**唯一的差別是取整。** 效力 4.5 對上擲骰 5:`CMBT` 進位成 5 → 成功,
`CAMP` 用 4.5 → 失敗。⚠ 引擎兩邊共用 `magic.EffectLevel`(有四捨五入)——
**這是具名的簡化**,差異最多 1 點。

> **判準:「另有一份程式碼」不等於「另有一條規則」。**
> [`201`](201-item-and-spell-fails.md) §4 把這一項列成未解,理由是
> 「`CAMP` 的路徑另有一份程式碼」—— 那只說明**要去讀**,不構成
> 「規則可能不同」的證據。BASIC 沒有共用副程式的話,同一條規則本來就會抄好幾份
> (`Item Breaks` 也是一模一樣的兩份)。

## 3. 對 remake 的影響

`castInCamp` 補上發動判定,沿用 `magic.EffectLevel` + `magic.Fizzles`。

⚠ **失敗照樣扣法力** —— 與戰鬥那一支沿用同一個具名決定
([`201`](201-item-and-spell-fails.md) §3:原版扣點的位置沒讀到)。

⚠ 順帶把 `Game.rand` 的型別從 `*combat.SeededRand` 改成介面
`combat.FloatRand`:**測發動之後的行為,就要先把發動判定拿掉**,
而那需要換得掉擲骰來源。這是 [`201`](201-item-and-spell-fails.md) §3 那一段
警告的同一個坑,只是這次發生在營地。
