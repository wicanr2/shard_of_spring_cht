# 211 — 營地睡覺的算式:兩個參數解出來,而手冊那一頁講的不是算式

> 輸入:`CAMP.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(呼叫端傳的兩個值、兩層迴圈的上界、逐人算式都讀出來)。

關掉 [`206`](206-poison-only-drains-while-resting.md) §4 的第一項 ——
worklist §8.1 C 組的第 7 項。

## 1. 兩個參數是「重複幾次」與「休息品質」

睡覺常式 `sub_12F6C` 只有**一個**呼叫端(`tools/ida/range_xref.py`),
而那一端把兩個值都填成 **1**:

```
010ECD  mov word ptr ds:723Ah, 1 / push 723Ah    ; 參數 1
010ED7  mov word ptr ds:723Ch, 1 / push 723Ch    ; 參數 2
010EE5  call sub_12F6C
```

常式開頭把它們拆開用:

```
012F6F  di = [bp+6] / ax = [di] / ds:7B40 = ax   ; ★ **外層迴圈上界**
012F77  ax = 1 …                                 ; i = 1 … ds:7B40
012F7E  ds:7B42 = ds:34F8(隊伍人數)             ;   內層:逐人
```

而 `[bp+8]` 在逐人算式裡挑兩檔:

| `[bp+8]` | 回復 | 法力 |
|---|---|---|
| `== 0` | 2 | +10 |
| `≠ 0` | **1** | **+5** |

營地固定傳 1 → 走後者。⚠ `== 0` 那一檔在 `CAMP` 裡是**到不了的**;
形狀上像旅店那一支(手冊 p.37 寫旅店回 2 HP / 10 SP)——
但**旅店在 `TOWN.EXE`**,那是另一份程式碼,沒有查。

## 2. 逐人算式(`0x12FDA`–`0x130F7`)

```
缺糧 ds:7B50 = (GROUPS 位移 23 ≤ 0) ? 1 : 0     ← ★ **整隊共用一個旗標**
中毒 ds:7B52 = (CHARS 位移 38 == 1) ? 1 : 0
狀態 == 5(死)→ 整個跳過

法力 += 5

中毒?
   是 → 生命 −= 缺糧 + 2          ← ⚠ **不回血**,是 if/else
   否 → 生命 += 1 − 缺糧

生命 < 1 → 生命 = 0、**法力也歸零**
否則     → 各自夾在最大值(位移 26 / 30)
```

食糧的扣除**在常式外面、逐人迴圈之外**:

```
010EF7  ds:66D0 = 17h / call 讀     ; 位移 23 = 補給品
010F00  dec ax
010F04  ds:66CA = 17h / call 寫回   ; ★ 整晚 **1 份**
```

## 3. 睡覺是「睡到天亮」,不是睡固定的小時數

```
010F46  mov word ptr ds:353Ah, 1Bh   ; 時 ← **27**
```

「時」的值域是 4–26([`107`](107-clock-is-four-levels.md)),所以 27 會被
四級進位捲成 **隔天的 4 點**。⚠ 這解釋了為什麼常式的「重複次數」參數是 1:
睡覺不是「跑 8 次每小時的結算」,是**一次結算 + 把時鐘推到隔天**。

## 4. 手冊 p.38 講的不是算式

先前引擎照手冊寫成:

| 引擎(舊) | 原版 |
|---|---|
| 每人耗 1 份食糧 | **整晚 1 份** |
| 吃不到的那個人扣 1 血 | 缺糧是**整隊**旗標,而且只**抵銷回復** |
| 中毒每小時扣 1 × 8 小時 = **8** | **缺糧 + 2**(吃飽 = 2)|
| 中毒的人先回 1 再扣 8 | 中毒**不回血** |

四項裡三項不對,而**每一項單獨看都像手冊寫的那樣**。

> **判準:手冊講「發生什麼事」,不講「怎麼算」。**
> 「中毒每小時扣 1 HP、睡八小時」讀起來像一條算式,而它其實只是在說
> 「中毒的人睡覺會虧」。⚠ 把敘述當算式抄進來,得到的數字會**大到四倍**,
> 而畫面上只是「中毒睡覺很慘」—— 與正確版本的體感一致,所以不會有人懷疑。
> ⛔ 手冊是第 3 級證據([`CLAUDE.md`](../../CLAUDE.md) §6),不要拿它當公式來源。

## 5. 對 remake 的影響

`town.CampSleep` 照 §2 重寫;`CampSleepHours` 換成 `CampSleepToHour = 27`,
睡覺改成「把時鐘的『時』設成 27 再推一格」。

⚠ **`InnSleep` 沒有動** —— 它的 2 HP / 10 SP 仍然只有手冊 p.37 當來源,
而 §1 的 `[bp+8] == 0` 那一檔剛好也是 2/10。**形狀吻合不等於讀到了**;
要定案得去讀 `TOWN.EXE`。
