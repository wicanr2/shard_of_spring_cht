# 213 — 能見度**就是繪製半徑**:世界地圖入夜會縮,迷宮同一套

> 輸入:`WRLDMOVE.EXE`、`MAZEMOVE.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 反組譯前先跑 `tools/ida/unlock_module.py`。
> 信心:**已確認**(兩支模組的繪製邊界都逐行讀出;置中偏移的算式獨立佐證)。

關掉兩件事:worklist §8.1 C 組的第 9 項(「地面上的天色有沒有真的縮小視野」),
以及 [`spec/08`](../spec/08-maze-scene.md) §3 標了很久的
「把能見度當半徑是**實作決定**,不是 RE 結論」。

## 1. 迷宮:邊界就是「中心 ± 能見度」

`MAZEMOVE` `0x1078C`–`0x107AE`:

```
01078C  ax = 中心座標
01078F  sub ax, ds:35B2h     ; ★ − 能見度  → ds:8E32(下界)
01079D  bx = 另一軸中心
0107A2  sub ax, ds:35B2h     ; ★ − 能見度  → ds:8E38
0107A8  add bx, ds:35B2h     ; ★ + 能見度  → ds:8E3A
```

`ds:35B2` 是**攜帶光的生效能見度**([`204`](204-light-burns-per-turn-and-offset-83.md) §2)。
兩軸各取 ±,**這就是切比雪夫半徑**,不是別的讀法。

## 2. 世界地圖:半徑是**天色**,而且會隨時辰改變

`WRLDMOVE` `0x11085` 是繪製常式,三個呼叫端(`0x10BDF` / `0x10FBC` / `0x11004`)
推的都是 **`ds:35B4`** —— 自然光(天色)的能見度:

```
010BC8  ax = ds:35B4 / cmp ax, ds:35B6 / jnz → 重畫
010BD8  push 35B4h / call sub_11085        ; ★ 半徑 = 天色
```

`ds:35B6` 是「上一次畫的時候是多少」——**天色一變就重畫**。

常式裡用它算邊界:

```
0110BD  di = [bp+6] / ax = [di]      ; 半徑
0110C4  add ax, ds:351Ah             ; 上界 = 世界 y + 半徑
0110CE  ax = ds:351A − 半徑          ; 下界
```

**所以世界地圖入夜是真的會縮的**,不是只有畫面變暗。
配上天色的四段([`204`](204-light-burns-per-turn-and-offset-83.md) §2.2):

| 時 | 4–5 | 6–13 | 14–16 | 17–18 | 19–26 |
|---|---|---|---|---|---|
| 能見度 | 3 | **4** | 3 | 2 | 1 |
| 視野 | 7×7 | **9×9** | 7×7 | 5×5 | **3×3** |

## 3. 置中偏移反過來證明「4 是滿的」

`USERLIB` `0x10578` 算 `ds:35CC = (4 − 生效能見度) × 17`(17 = 圖塊邊長),
而兩支模組都把它加進繪製起點:

```
WRLDMOVE 0110B0  ax = ds:35CC + ds:35BA + 16   → 起始像素 y
WRLDMOVE 0110D5  ax = ds:35CC + ds:35B8        → 起始像素 x
```

**縮小之後把起點往內推剛好被裁掉的格數** —— 視野縮小但仍然置中。
這個算式只有在「滿視野的半徑是 4、實際半徑是能見度」時才成立,
所以它是 §1/§2 的獨立佐證:**不必相信我對邊界那幾行的判讀,
光看這個偏移就知道半徑是能見度。**

> **判準:一個「只是把東西挪一挪」的算式,常常把它旁邊那個量的語意寫死了。**
> `(4 − v) × 17` 裡的 4 與 17 都是可以對照的:17 是圖塊邊長、
> 4 是滿視野 9×9 的半徑。兩個都對得上,`v` 就只能是實際半徑。

## 4. 對 remake 的影響

- 世界地圖的繪製迴圈加上半徑裁切(`engine/scene.go` 的 `worldScene.Draw`),
  半徑取 `g.party.Visibility` —— 在地面上那就是天色
  ([`204`](204-light-burns-per-turn-and-offset-83.md) §2)
- `maze.VisibilityIsRadius` 的說明從「實作決定」改成「已確認」

⚠ **這一條讓「入夜」變成一個真的機制**:晚上走世界地圖看得到的範圍只有 3×3,
而遭遇檢查掃的是 3×3 鄰域([`212`](212-world-fixed-events-are-two.md) §3)——
玩家在夜裡幾乎是貼著遭遇範圍在走。⛔ 不要因為「玩起來不方便」就放寬它。
