# 216 — 全遊戲只有兩首曲子:沒有場景 BGM 可以接

> 輸入:十一支 BASIC 模組 + `USERLIB.EXE`(SHA-256 見 [`00-inputs.md`](00-inputs.md))。
> 信心:**已確認**(全模組字串表清點,附掃描分母)。

關掉 worklist 的 **E7**「世界地圖、地城、城鎮的 BGM 沒有規劃」——
**那不是缺口:原版沒有那些曲子。**

## 1. 清點:樂譜只在兩支執行檔裡

`PLAY` 巨集的樂譜是**字串常數**([`148`](148-the-game-has-music.md)),
所以清點的方法是掃字串表而不是掃程式碼。
`tools/dgroup_strings.py` 逐支模組跑過,比對「以 `T<n>` / `O<n>` / `L<n>` /
`MB` / `ML` / `MS` / `MN` 開頭」的字串:

| 模組 | 命中 |
|---|---:|
| `MAZEMOVE` | **10**(整首 18 段,其餘不以巨集字母起頭)|
| `START` | 1 —— ⚠ **誤判**:`MS DOS version by Digital Illusions, Inc.` |
| 其餘九支(`MENU` `TOWN` `CMBT` `CAMP` `WRLDMOVE` `CHARUTIL` `MTEST` `MIO2` `WSIO`)| **0** |

加上 `USERLIB.EXE`(原生組語,不在 BASIC 字串表裡)的 5 段
`MB T50 O3 L8 ML …`(檔案位移 `0x180E`–`0x1868`)。

**全遊戲兩首:通關曲(18 段,`T108`)與死亡曲(5 段,`T50`)。**

⚠ `START` 那一筆是這次清點裡唯一的誤判,而它是靠**看內容**排除的 ——
`MS ` 開頭的樣式抓得到「MS DOS」。**樣式清點一定要把命中逐條看過**,
否則分母會多一個。

## 2. 所以 E7 沒有東西可接

引擎現在接了兩處:結局(`music.Ending`)與全隊陣亡(`music.Userlib`)。
**那就是全部。** 世界地圖、地城、城鎮在原版是**安靜的** ——
1986 年的 PC 喇叭遊戲,音樂通常只出現在開頭與結尾。

⚠ [`spec/15`](../spec/15-game-shell.md) §A1 寫「音樂:`music.Title` 若存在」——
**不存在**。標題畫面沒有曲子,那一行的「若存在」是對的,
但容易被讀成「還沒接」。

⛔ **不要為了「有背景音樂比較完整」而循環播放通關曲。**
[`spec/13`](../spec/13-sound.md) §5 已經寫過同一條:
**寧可不接,也不要接到一個看起來合理的錯位置** ——
玩家聽到的是「這裡本來就有音樂」,不會知道它放錯了。

> **判準:「引擎少了 X」與「原版沒有 X」要分開問。**
> worklist 把 E7 記成「BGM 的觸發點沒有規劃」,那句話預設了觸發點存在。
> 與 [`206`](206-poison-only-drains-while-resting.md)(中毒移動扣血)
> 是同一種形狀:**先確認原版有做,再說引擎缺了什麼**。
