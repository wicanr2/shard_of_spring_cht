## 1. 入口:`0x15534`

[`186`](186-monster-ai-target-placement-cast.md) §3 的施法分支跳到這裡。開頭三件事:

```
015534  di = ds:9352 → [di+6A7A]      ; 目前行動的單位
015540  ax = [屬性 14] → ds:9B0A       ; ★ 系別
01554D  ds:9B0C = 0
015553  ax = [屬性 7]  → ds:9B0E       ; 法力
015563  cmp ds:9314(回合數), 1
        > 1 → 0x1556D、否則 → 0x155B0
```

回合 > 1 那一條是三個字面常數:

```
系別 1 → ds:98D8 = 3       (FIRE STORM)
系別 3 → ds:98D8 = 8       (TEMPEST)
系別 4 → ds:98D8 = 0Ch(12)(HAIL STORM)
其餘   → 掉回第一回合那條路
```

`ds:98D8` 是法術編號。**與 [`170`](170-monster-ai-casts-by-spell-family.md) §4 逐值相同**,
而且「系別 2 / 5 沒有分支」在這裡看得更清楚:它們**掉回隨機挑**那一段。

## 2. 投入點數:`0x1573A`–`0x15791`

```
01573A  di = 目前單位 + 69h            ; 屬性 7
015749  bx = [di+6822h]                ; 法力
01574D  si = 法術編號 × 2
015751  dx = [si+73C8h]                ; ★ 欄 5 法力單價(docs/re/172 §2)
015755  shl dx, 1                      ; dx = 單價 × 2
015757  cx = dx
015759  dec dx                         ; dx = 單價 × 2 − 1
01575A  cmp bx, dx / jg
   →   ds:93A2 = cx  = 單價 × 2        ; 法力夠
   否則 ds:93A2 = 法力                  ; 不夠 → 全押
01578D  [屬性 7] −= ds:93A2             ; 扣法力
```

`ds:93A2` 是投入的點數([`74`](74-spell-and-item-columns.md) §1、[`201`](201-item-and-spell-fails.md) §1),
`ds:73C8` 是欄 5 的陣列基底([`172`](172-spells-column-arrays.md) §2 的五個接縫一個不差)。

**規則:怪物永遠投入「剛好兩級」的量,法力不足時把剩下的全部押上去。**
判斷寫成 `法力 > 單價×2 − 1`,也就是 `法力 ≥ 單價×2`。

⚠ 這也解釋了 `186` §3 的硬門檻為什麼是 `法力 > 1`:最便宜的法術單價是 1,
兩級要 2 點 —— **法力剩 1 的怪物連一次都放不出來**,擋在前面比較省事。

## 3. 目標格:把游標捲到鎖定的那個人身上

`0x157CD`–`0x158C2` 是一個**四方向的捲動迴圈**:

```
取屬性 15(鎖定的目標)→ 讀它的屬性 1(y)
  y < ds:9348 → call sub_17136      ; 往上捲
  y > ds:9348 → call sub_17677      ; 往下捲
讀它的屬性 0(x)
  x > ds:9346 → call sub_174B5
  x < ds:9346 → call sub_172F7
0x15887  再讀一次目標的 x / y
0158C2   兩軸都等於 ds:9346 / ds:9348 才往下走,否則 jmp 0x157B1 回去捲
0158FE   jmp 0x14F20                 ; ★ 與玩家共用的施法路徑
```

`ds:9346` / `ds:9348` 是游標([`195`](195-group-spell-round-gate-and-area.md) §2、
[`215`](215-monster-step-axis-preference.md) §1),而 `0x14F20` 起的那一段
正是玩家按下施放之後走的路:`0x14F26` 查欄 3 的效果類別、
`0x14F44` 拿 `ds:9346` / `ds:9348` 去找「站在游標那一格的是誰」、
群體傷害則走 `0x1505A` 的 5×5(`195` §2)。

**所以怪物不另外挑格子** —— 它把游標移到自己鎖定的那個人身上,
接下來的判定與玩家完全一樣。單體法術打那個人,群體法術以那個人為中心的 5×5,
**同一塊裡的怪物也會被打到**([`208`](208-group-spell-hits-everyone.md))。

⚠ 那四支 `sub_171xx` / `sub_174B5` / `sub_17677` 是**捲畫面**的常式,
依 [`CLAUDE.md`](../../CLAUDE.md) §1.2 不往下追:它們造成的效果(游標移到目標)
是從迴圈的結束條件讀出來的,不是從常式內部。
