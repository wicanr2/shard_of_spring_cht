# 28 — 輸入語意:命令鍵與各畫面的有效鍵

日期:2026-08-13
接續:[`27-chars-dat.md`](27-chars-dat.md)
子系統:`CLAUDE.md` §2.2 的 **J. 輸入語意(不含 BIOS 層)**

## 結論

命令鍵的慣例是 **`X)字` —— 括號前的字母就是要按的鍵**。
從六支模組的提示字串盤點出各畫面的有效鍵,`CAMP.EXE` 的命令集最完整。

依 `CLAUDE.md` §1.2,這裡只解「哪些鍵在哪個畫面有效、對應什麼動作」,
**不追鍵盤掃描碼怎麼進緩衝區**。

⚠ 本文的證據是**提示字串**,不是輸入處理的程式碼。
按 §2.1 未達 RE-DONE —— 提示可能與實作不一致
(daemon_winter 踩過:選人畫面的提示只寫 Enter,實際還吃方向鍵)。

## 1. `CAMP.EXE`(紮營選單,命令最多)

| 鍵 | 動作 |
|---|---|
| `P` | 列印角色 |
| `S` | 睡眠 |
| `C` | 施法 |
| `R` | 重排隊伍 |
| `T` | 交易 |
| `D` | 丟棄 |
| `E` | 裝備 |
| `H` | 狩獵 |
| `I` | 鑑定 |
| `U` | 使用道具 |
| `ESC` | 離開 |

**十個命令 + ESC。** 多數命令之後會再問「哪一個角色」,
提示形式是「角色編號 ?, (ESC exits)」—— 所以是**兩段式輸入**。

## 2. `TOWN.EXE`(城鎮)

| 情境 | 有效鍵 |
|---|---|
| 城鎮主畫面 | 建築物選擇、`#` 檢視角色、`ESC` 離開 |
| 商店 | 道具編號、`ESC`、**任意鍵翻頁** |
| 治療所 | 角色編號、`ESC`;付款 `Y`/`N` |
| 訓練 | 角色編號 → 技能、`ESC` |
| 酒館 | `T` 交談、`B` 買食物、`ESC` |

## 3. `CMBT.EXE`(戰鬥)

與其他畫面**不同**:有方向鍵與數字鍵盤。

| 提示 | 意義 |
|---|---|
| `KEYPAD TEMPLATE` | 有一張數字鍵盤對照圖 |
| `Use arrow keys to …` | 方向鍵移動/選取 |
| `Hit PgDn key` | 翻頁 |
| `[ESC]` / `(ESC to Exit)` / `(ESC cancels)` | 取消 |
| `(ENTER exits)` | 確認離開 |
| 藥水:`Y)ourself` / `T)oss it to another` | 兩選一 |

**戰鬥是唯一大量使用方向鍵與 PgDn 的畫面。**
這對 remake 的輸入層設計是關鍵差異 —— 其他畫面只吃字母與 `ESC`。

## 4. `MAZEMOVE.EXE`(地城)

寶石謎題:`B`、`G`、`V`、`R` 四選一(顏色首字母),或 `ESC`。

## 5. `MENU.EXE`(安裝／設定)

`Y`/`N`(是非)、`Y`/`N`/`Q`、`F`(完成設定)、任意鍵繼續。
含換磁片、螢幕型別(LCD/EGA)、可存角色數上限等設定提示。

**這些是安裝流程不是遊戲玩法**,中文化時屬於另一類。

## 6. 兩個對 remake 有用的觀察

1. **`X)字` 慣例貫穿全部模組** —— 所以命令鍵可以從提示字串機械地抽出來,
   不必逐一反組譯。中文化時**括號前那個字母要保留**
   (否則玩家不知道按什麼),這與 daemon_winter 的做法一致。
2. **兩段式輸入很普遍**:先選命令,再選對象(角色編號),
   每一段都可以用 `ESC` 退回。remake 的輸入層要支援這個模式。
