# 34 — 五個種族,與角色記錄的欄位名

日期:2026-08-13
接續:[`33-quiz-validates-columns.md`](33-quiz-validates-columns.md)
子系統:**D. 角色／隊伍資料**

## 結論

`CHARUTIL.EXE` 裡有**五個種族名**與角色列表的**欄位標頭**,
兩者一起把 [`27`](27-chars-dat.md) 未解的角色記錄補上了語意骨架。

## 1. 五個種族

模組 `+0x2F8C` 起連續五筆(順序即索引):

```
Humans   Trolls   Dwarfs   Elf   Gnomes
```

**信心等級:已確認**(連續、同一種排列、緊接著是不相關的 `errors`)。

⚠ 一開始用「長度 ≥ 6 的可讀字串」去掃,**`Elf`(3 字元)被漏掉** ——
症狀是 `Dwarfs` 與 `Gnomes` 之間有一段 `0x22` 的間隙,而其他相鄰間隔都是 `0x12`。

**判準:掃字串時,間隔不規則的地方要回去看原始位元組。**
最小長度過濾器會安靜地吃掉短字串,而**被吃掉的那個不會留下任何痕跡** ——
只有間隔會露餡。

`Gnomes` 與 [`33`](33-quiz-validates-columns.md) §1 的題目
(「Gnome 角色的智力加值」)對得上,**證實種族確實有屬性修正**。

## 2. 角色列表的欄位標頭

```
#) Name        Race   Class   Level   Status
```

所以角色記錄至少有:**名稱、種族、職業、等級、狀態**五個欄位。

`CAMP.EXE` 與 `TOWN.EXE` 另有屬性名清單:

```
Speed   Strength   Intellect   Endurance   Skill
```

**五個屬性。** 而 [`27`](27-chars-dat.md) §2 在角色記錄 `+0x0B` 起看到
**七個落在 9–11 的 16-bit 值** —— 數目對不上(5 vs 7),
所以「那七個是屬性」的形狀推測**仍然不能成立**。
可能是五個屬性加兩個別的,也可能起點不對。**維持未解。**

## 3. 其他佐證

| 字串 | 意義 |
|---|---|
| `Skills left:` | 建角時有技能點數配置 |
| 10 個 `0` 的字串 | 與 [`27`](27-chars-dat.md) §3 的技能旗標串同形 |
| `Party #0`、`Gold:`、`Provisions:` | 隊伍記錄的欄位(`GROUPS.DAT`)|
| `Saved in the month of the …` | 存檔含**月份名**,與 `TITLES.DAT` 之類的名稱表相關 |
| `Currently in the … / Wilderness / maze:` | 存檔記錄所在位置(野外 or 地城編號)|

**`GROUPS.DAT` 的欄位因此有了候選**:隊伍編號、金幣、糧食、月份、所在位置。
[`27`](27-chars-dat.md) §4 說該檔出貨時幾乎全空,現在知道**它應該長什麼樣**了。

## 4. 尚未解開

| 項目 | 狀態 |
|---|---|
| 種族修正的**數值** | 未解 —— **已排除三種存放形式**,見 §5 |
| 角色記錄裡種族/職業/等級的位移 | 未解 |
| `+0x0B` 起那七個值 | 未解(與五個屬性數目對不上)|
| `GROUPS.DAT` 的實際佈局 | 未解(欄位候選已知)|

## 5. 種族修正表:已排除的搜尋空間

5 種族 × 5 屬性 = 25 格,值域應該很小(題庫問的是「Gnome 的智力加值」)。
在 `CHARUTIL.EXE` 模組本體裡掃過三種可能的存放形式:

| 假設的形式 | 結果 |
|---|---|
| 連續 ≥20 個 16-bit 小整數(−3…+3) | **0 段** |
| 連續 ≥20 個小 byte(0…8) | **0 段** |
| ASCII 形式(含 `+`/`-`/數字的字串) | **0 條** |

**三種都不成立。** 剩下的可能:

1. 表在**別的模組**(建角流程可能不只 `CHARUTIL`)
2. 表在 `CHARUTIL` 但落在**未被反組譯的 62.8%** 裡(該模組解鎖到 37.2%)
3. 修正值**寫死在程式碼裡**(五個種族各一段 `if`,不成表)
4. 值域比我假設的大(例如以百分比或倍率存)

⚠ 把這個排除記下來,是為了讓後續**不要重複掃同一批形式**。
負面結果只有寫下來才有價值 —— 否則下一個人會再掃一次。
