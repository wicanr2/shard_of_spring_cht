# 54 — 子系統 F 收尾:圖塊 → 圖形的對應

日期:2026-08-14
接續:[`53-world-tiles-towns-and-draw-renderer.md`](53-world-tiles-towns-and-draw-renderer.md)
子系統:**F. 世界地圖**

## 結論

**`WRLDITEM.PIC` 的第 k 行 = 圖塊值 k + 10。** 零例外。

加上 [`53`](53-world-tiles-towns-and-draw-renderer.md) 的 `FASTWRLD.BIN`(圖塊 1–9),
**世界地圖上每一個出現過的圖塊值都有確定的圖形來源**。

**F 判定為 RE-DONE**(四項條件逐條核對見 §4)。

## 1. 派工的兩條路

`WRLDMOVE.EXE` 取到圖塊值之後分兩路:

```
0x1116C–0x112C2   圖塊 1–9、11  →  PUT 點陣圖(ds:0xCA1C 起,各 92 bytes)
                                    ([`52`](52-world-map-reader-and-shared-grid.md) §2)

0x112CC 起        其他值        →  DRAW 向量:
0112DC  mov  bx, ds:0CF92h      ; 圖塊值
0112E0  shl  bx, 1
0112E2  shl  bx, 1              ; × 4
0112E4  add  bx, 0C980h         ; ★ 字串描述子陣列
0112E8  int  3Eh, 36h           ; DRAW
```

**`ds:0xC980 + 圖塊值 × 4`** —— 4 bytes 是 BASIC 的字串描述子
([`43`](43-common-block-and-array-indexing.md) §3),所以那是字串陣列 `A$(圖塊值)`。

**信心等級:已確認**(指令直接讀出)。

## 2. 對應規則:行號 + 10

`WRLDITEM.PIC` 有 **30 行**,其中 **7 行是空的**(第 1、4、9、12、23、24、29 行)。

若第 k 行對到圖塊 `k + off`,掃描 `off` = 0…19:

| `off` | 不合數 |
|---:|---:|
| **10** | **0** |
| 其餘 | > 0 |

`off = 10` 時:

| 空行 | → 圖塊 | 為什麼可以是空的 |
|---|---:|---|
| 1 | **11** | **用點陣圖**(海洋,`FASTWRLD` 的第 11 張路徑)|
| 4, 9, 12, 23, 24, 29 | 14, 19, 22, 33, 34, 39 | **地圖上從未出現這些值** |

反過來,**地圖上用到的 20 個向量圖塊值全部對到非空行**。

**這不是「大致吻合」,是 7/7 加 20/20。** 隨機對應不可能同時滿足兩邊。

⚠ 唯一的例外是**圖塊 0**(224 格,全在地圖邊緣)——
`0 − 10 = −10` 不在檔案裡,所以它走另一條路或根本不繪製。
邊緣格不會進入視野,與觀察一致。**推測,未從程式碼確認。**

### 最強的一條互證

[`53`](53-world-tiles-towns-and-draw-renderer.md) §3 從**空間分布**推出:

> 圖塊 12 排成 8 格的垂直線,而唯一的圖塊 13 恰好在正中間 ——
> 那是「一段通道 + 中間一個入口」的形狀。

現在把圖形畫出來:**圖塊 12 是橋面,圖塊 13 是帶城門的關卡。**

```
圖塊 12                     圖塊 13
####### #########           #               #
                            #    #:###:#    #
########### #####           #   # :   : #   #
########### #####           # :::::::::::#  #
```

**位置分布**與**圖形內容**是兩個完全獨立的來源,結論一致。

## 5. 方法

`off = 10` 不是猜出來的,是**掃描 0–19 全部偏移量、用「零不合」挑出來的**。
而「不合」的定義用了兩個方向的約束:

- 空行 → 那個圖塊值必須有別的圖形來源,或根本沒用到
- 用到的圖塊值 → 必須對到非空行

**單方向的約束會有多個解;雙方向同時成立的只有一個。**
這與 [`50`](50-sqz-maze-format.md) §2 用「所有解析取交集」定標記字元是同一個手法 ——
**先把約束寫全,再讓程式找唯一解,不要用眼睛猜。**
