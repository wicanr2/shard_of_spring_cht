## 1. 移動判斷:5–10 阻擋

`MAZEMOVE.EXE` `0x10468`–`0x10496`:

```
010468  mov  ax, 51h              ; 81
01046B  imul word ptr ds:8DC2h    ; 欄 × 81
01046F  mov  di, ax
010471  add  di, ds:8DC0h         ; + 列
010475  shl  di, 1
010477  cmp  word ptr [di+6822h], 5
01047C  mov  bx, 0
01047F  jl   short loc_10482
010481  dec  bx                   ; bx = −1 若 格值 ≥ 5
010482  cmp  word ptr [di+6822h], 0Ah
010487  mov  dx, 0
01048A  jg   short loc_1048D
01048C  dec  dx                   ; dx = −1 若 格值 ≤ 10
01048D  and  dx, bx               ; 兩者皆真 → 5 ≤ 格值 ≤ 10
01048F  and  dx, dx
010491  jnz  short loc_10496
010496  mov  word ptr ds:8DC4h, 0 ; ★ 清掉「可移動」旗標
```

**`5 ≤ 格值 ≤ 10` → `ds:8DC4h = 0`。**

而 [`55`](55-sqz-decoder-from-code.md) §5 的統計裡,
**格值 7 佔了所有非零格的 88%(3,553 / 4,020)** —— 它落在阻擋區間內。
**7 是牆。信心等級:證據充分**(行為 + 出現頻率兩項)。

## 2. 繪製判斷:0 / 18 / 19 不畫,負值取絕對值

`0x107FF`–`0x1085E`:

```
0107FF  cmp  word ptr [di+6822h], 0
010804  jl   short loc_10809       ; ★ 格值 < 0
010809  mov  ax, [di+6822h]
01080D  neg  ax                    ; ★ 取絕對值
01080F  mov  ds:8E3Eh, ax
   …
01082B  cmp  word ptr ds:8E3Eh, 13h    ; 19
010836  cmp  word ptr ds:8E3Eh, 12h    ; 18
010843  cmp  word ptr ds:8E3Eh, 0
010850  not  bx / and bx, bx
010854  jnz  short loc_10859
010856  jmp  loc_108A6                 ; ★ 是 0/18/19 → 跳過繪製
010859  cmp  word ptr ds:8E3Eh, 7
01085E  jz   short loc_10863           ; 7 另有分支
```

**格值可以是負的**,而且負值的絕對值才是繪製編號 ——
[`55`](55-sqz-decoder-from-code.md) §5 統計到的 `−14`、`−13` 因此**不是雜訊**。
⚠ 負號代表什麼(背面?已探索?)**未解**。

## 3. `MAZEDATA` 欄 2 / 3 = 起始列 / 起始欄

[`51`](51-mazedata-and-world-entrances.md) §4 當時因為「格子內容沒有乾淨判準」而只標假設。
現在有了 §1 的阻擋規則,判準就出來了 —— **起始位置必須可通行**:

| 讀法 | 12 個關卡中可通行的 |
|---|---|
| `格[欄2][欄3]` | **12 / 12** |
| `格[欄3][欄2]` | 9 / 12(其中兩個是格值 7 與 10,都在阻擋區間)|

**信心等級:證據充分。** 12/12 對 9/12,而且失敗的那幾個剛好落在牆上。

## 4. `MAZEDATA` 欄 7 = 文字記錄數 − 1

| 關卡 | 文字檔 | 記錄數 | 欄 7 |
|---:|---|---:|---:|
| 0 | `DT0` | 2 | **1** |
| 1 | `DT1` | 8 | **7** |
| 2 | `DT2` | 8 | **7** |
| 3 | `DT3` | 19 | **18** |
| 4 | `DT4` | 2 | **1** |
| 5 | `DT5` | 18 | **17** |
| 6 | `DT6` | 6 | **5** |
| 7–11 | `DT7` | 9 | **8** |
| 12 | `DT51` | 15 | **14** |

**13 / 13,零誤差。** 欄 7 是那個關卡文字的**最大索引**
(BASIC 的 `DIM` 上界,或迴圈上限)。

兩個來源獨立:一邊是 `MAZEDATA.BIN` 的數值,一邊是數 `DT*TEXT.DAT` 的行數。

## 5. 欄 4:未解

值域只有 `{1, 3}`(第 13 列是 0,未使用)。

**假設是「起始朝向」**,但用「起始格在該方向的鄰格是否可通行」去測,
四種方向慣例最好的一種只有 **9/12**:

| 慣例 | 命中 |
|---|---|
| `1=北 2=東 3=南 4=西` | 9/12 |
| `0=北 1=東 2=南 3=西` | 4/12 |
| 其餘兩種 | 2–4/12 |

⚠ **9/12 不足以定案**,而且「朝向」本來也不要求那個方向可通行
(進門時面對牆是合理的)。**所以這個測試既無法確認也無法否證。**

**標為未解。** 要定案得讀 `MAZEMOVE` 裡使用這個值的地方。
