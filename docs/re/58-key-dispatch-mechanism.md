## 結論

1. **`ds:681Ah`([`43`](43-common-block-and-array-indexing.md) §4 認出的「鍵盤字元」)
   只被共用的輸入編輯常式使用** —— 七支模組**全部**只拿它跟同一組五個值比較。
2. **選單鍵不是用數值比較,是用單字元字串常數做字串比對。**
3. **`CAMP` 主選單的提示鍵集合與實作鍵集合完全相同(10/10)** ——
   [`28`](28-input-semantics.md) 標的「提示與實作是否一致未驗」,第一個畫面驗過了。

## 1. `ds:681Ah` 是共用輸入常式的,不是遊戲按鍵

掃七支模組對 `ds:681Ah` 的**全部**比較:

| 模組 | 比較的值 |
|---|---|
| 七支**全部** | `08h`(BS)、`0Dh`(CR)、`1Bh`(ESC)、`20h`(空白)、`7Eh`(`~`)|

**七支一模一樣** —— 那是 `MASTER.INC`([`47`](47-source-filenames-and-master-inc.md))
裡的**輸入行編輯**:退格、確認、取消,加上可列印範圍 `20h`–`7Eh` 的邊界。

⚠ 所以 [`43`](43-common-block-and-array-indexing.md) §4 把 `ds:681Ah` 標成「鍵盤字元」是對的,
**但它不是遊戲選單讀的那個東西**。用它去找按鍵表會一無所獲 —— 我先試了這條路。

## 2. 選單鍵的機制

`CAMP.EXE` `0x105D6` 起:

```
0x105D6  mov  bx, 703Ch      ; ← 'S' 的字串描述子
0x105D9  mov  ax, 7032h      ; ← 玩家輸入的字串
         <執行期字串比較>
0x105EA  mov  bx, 7042h      ; 'C'
0x105ED  mov  ax, 7032h
0x105FE  mov  bx, 7048h      ; 'R'
   …
0x106B4  mov  ax, 7072h      ; 'P'
```

**十次連續的字串比對**,每次拿輸入去比一個**單字元字串常數**。

那些常數在資料段裡是**連續排列的**(`0x703A`、`0x7040`、`0x7046`…,間距 6),
所以用[文字清單](generated-text-inventory.json)可以直接把位址翻回字元。

⚠ **這也是為什麼掃立即數找不到按鍵**:程式碼裡沒有 `cmp al, 'S'`,
只有 `mov bx, <描述子位址>`。我先掃了 ASCII 立即數(`tools/ida/find_ascii_cmp.py`),
在 `TOWN` 只找到一個叢集,而且是 loader stub 在解析路徑的 `:` 與 `\`。
**工具沒中,先問「這個語言會產生這種指令嗎」。**

| 提示文字 | 鍵 |
|---|---|
| ` P)rint char(s)` | P |
| ` S)leep` | S |
| ` C)ast spell` | C |
| ` R)eorder` | R |
| ` T)rade` | T |
| ` D)rop` | D |
| ` E)quip` | E |
| ` H)unt` | H |
| ` I)dentify` | I |
| ` U)se an item` | U |
| ` ESC to leave` | (ESC)|

程式碼的比對鏈(`0x105D6`–`0x106B4`):**S C R T E H I D U P**

**兩個集合完全相同,10/10。** 順序不同是正常的(顯示順序 vs 測試順序)。

**信心等級:已確認**(提示來自資料檔的位元組,鏈來自指令;兩個來源獨立)。

## 4. 其他畫面:尚未驗證

用同一支工具掃其餘六支模組,只有 `CAMP` 的主選單鏈是乾淨的:

| 模組 | 抽到的叢集 |
|---|---|
| `CAMP` | `SCRTEHIDU`(主選單 ✅)、`ERIT`、`CRCR…` |
| `CHARUTIL` | `JFDIRICI`、`HFT` |
| `TOWN` | `HEG` |
| `MENU` | `12M`、`IIIT` |
| `CMBT` / `MAZEMOVE` / `WRLDMOVE` | 只抽到共用常式的 `099…` |

**雜訊來源有二**:共用輸入常式的數字範圍檢查(`0`、`9`)會被誤收;
而聚類門檻(相鄰 `0x60` bytes)對分散的分支不適用。

⚠ **不要把上表當成按鍵表。** 它是工具的中間產物,只有 `CAMP` 那一列經過人工核對。
