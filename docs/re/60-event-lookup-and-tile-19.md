## 1. 事件查表(`MAZEMOVE.EXE` `0x11752`)

```
011752  mov  di, [bp+0Ah]      ; 參數:目前的列
011755  mov  bx, [di]
011757  mov  si, ax            ; 迴圈變數 i
011759  shl  si, 1
01175B  cmp  bx, [si-7710h]    ; ★ 事件表欄 0(觸發列)
01175F  dx = −1 若相等
011765  mov  bx, ax
011767  add  ax, 6Ah           ; ★ + 106 → 換到欄 1
01176A  mov  di, ax
01176C  shl  di, 1
01176E  mov  cx, [di-7710h]    ; ★ 事件表欄 1(觸發欄)
   …
0x115BF / 0x118E3  cmp ax, 69h ; 迴圈上界 105 → 共 106 項
```

`-7710h` 當成無號位移就是 **`0x88F0`** —— 事件表的基底。
**欄距 106、共 106 項,與 [`59`](59-de-eff-event-table.md) 從資料側推出的排法逐字相同。**

### ⚠ `BSAVE` 標頭的位址不是載入位址

九個 `DE*EFF.BIN` 的標頭都寫 `off=0x6822`(那是[「當前地圖」陣列](52-world-map-reader-and-shared-grid.md)),
但程式實際把它當成 `ds:0x88F0` 的陣列在用。

BASIC 的 `BLOAD file$, offset` **由程式指定位址**,檔案標頭裡的那個只記錄「當初從哪裡存的」。
**判準:`BSAVE` 標頭的 offset 是作者端的資訊,不是載入端的。**
([`49`](49-h-closure.md) §1 的 `MONST` 剛好兩邊相同,那是巧合,不能推廣。)

## 2. 圖塊 19 = 隱形的文字觸發格

把每一層的事件表(用 `MAZEDATA` 欄 5/6 對到正確的 `DE`/`DG` 檔)
與迷宮格對起來,**「目標 > 100」的 110 個事件**踩在:

| 圖塊 | 事件數 | |
|---:|---:|---|
| **19** | **96** | **87%** |
| 26 | 4 | §4 |
| 27 | 3 | 鐵柵門([`57`](57-g-closure.md) §4)|
| 25 | 2 | 箱子 |
| −13 / −14 | 4 | §3 |
| 0 | 1 | — |

而 [`56`](56-maze-tile-classes-and-mazedata-columns.md) §2 已從程式碼確認
**圖塊 19 是「跳過不繪製」的三個值之一**。

**看不見 + 87% 的文字事件踩在上面 = 隱形觸發格。**
兩個性質分別來自程式碼與資料統計,互相獨立。

## 3. 負格值 = 跨關卡的樓梯

[`55`](55-sqz-decoder-from-code.md) §5 統計到六個迷宮裡只有 **4 個負值格**,
[`56`](56-maze-tile-classes-and-mazedata-columns.md) §2 從程式碼看到「負值取絕對值後當繪製編號」,
但**負號的意義未解**。

現在對起來了:

| 位置 | 格值 | 事件目標 |
|---|---:|---:|
| `DG5` (9, 29) | **−14** | 501 |
| `DG5` (72, 27) | **−13** | 501 |
| `DG51` (34, 3) | **−14** | 502 |
| `DG51` (52, 5) | **−13** | 502 |

**4 個負值格 ↔ 4 個「沒有文字」的事件,一對一,零例外。**

而 `|13|` = 下樓梯、`|14|` = 上樓梯([`57`](57-g-closure.md) §4 的渲染),
`DG5` 與 `DG51` 正是同一個地城的兩半。

**所以:負號 = 「這個樓梯通到另一個關卡檔」。**
`501` 是 `DG5` → `DG51`,`502` 是回程。
它們不需要文字,所以 [`59`](59-de-eff-event-table.md) §2(a) 才找不到對應的 `DT` 記錄。

**信心等級:已確認。** 4/4、方向相反、地城成對,三項同時成立。

## 4. 圖塊 26 與 `403`–`406`

`DE4EFF` 的四個沒有文字的目標:

| 位置 | 方向 | 目標 | 格值 |
|---|---:|---:|---:|
| (72, 46) | 1(北)| 403 | **26** |
| (72, 48) | 1(北)| 404 | **26** |
| (78, 46) | 3(南)| 405 | **26** |
| (78, 48) | 3(南)| 406 | **26** |

而同一個檔裡**有**文字的 `401` / `402` 踩在圖塊 **19** 上。

四個位置排成 2 × 2、兩兩朝向相反 —— 那是「兩端各兩格」的形狀。
**假設:另一種轉移裝置**(關卡 4 的迷宮是 `DG1`,而 `DT4` 的文字提到「塔頂」)。
⚠ 未驗證。
