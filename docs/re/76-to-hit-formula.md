# 76 — 命中判定的公式,以及 `ITEMS` 兩欄的雙重身分

日期:2026-08-14
接續:[`75-character-record-equipment.md`](75-character-record-equipment.md)
子系統:**J. 戰鬥規則** × **E. 規則資料表**

## 結論

`CMBT 0x13647`–`0x136C5` 是命中值的計算,而它同時解掉
[`74`](74-spell-and-item-columns.md) §3 留下的問題:
**`ITEMS.DAT` 欄4 / 欄5 對裝備與對魔法道具是兩套意思**,兩套都從程式碼看到了。

## 1. 公式

```
命中 = ( 屬性9[攻] − 欄5[防禦者的防具] + 欄5[攻擊者的武器] ) × 4
       + 30   若 屬性8[防] ≤ 1
       + 12   若 屬性10[攻] = 屬性10[防]
```

逐條對應:

```
013647  di = ds:93A6h            ; 攻擊者
01364D  add di, 87h              ; + 135 = 屬性 9
013653  mov dx, [di+6822h]

013657  si = ds:93A4h            ; 防禦者
01365D  add si, 4Bh              ; + 75  = 屬性 5(防具)
013662  mov si, [si+6822h]       ; → 防具的物品編號
013668  sub dx, [si+7702h]       ; − ITEMS 欄5

01366C  add bx, 3Ch              ; + 60  = 屬性 4(武器)
013673  mov di, [di+6822h]       ; → 武器的物品編號
013679  add dx, [di+7702h]       ; + ITEMS 欄5

01367D  shl dx, 1 / shl dx, 1    ; × 4
013683  mov ds:9768h, ax         ; 命中值

01368D  cmp word ptr [di+6822h], 1     ; 屬性 8[防]
013697  add word ptr ds:9768h, 1Eh     ; ≤ 1 → +30

0136B7  cmp bx, [si+6822h]             ; 屬性 10 兩邊比
0136C0  add word ptr ds:9768h, 0Ch     ; 相同 → +12

0136C5  int 3Dh; 34 … int 3Fh; 77      ; 擲骰
```

**信心等級:已確認**(逐條指令讀出)。

## 2. `ITEMS.DAT` 欄4 / 欄5 的雙重身分

| 欄 | 對**裝備** | 對**魔法道具** |
|---:|---|---|
| 4 | **傷害 / 護甲值** | 法術編號([`74`](74-spell-and-item-columns.md) §2)|
| 5 | **命中加值** | 投入的法術點數 |

兩邊都有程式碼證據:

- **欄5 當加值**:上面 §1 的 `sub` / `add` —— 直接進命中公式
- **欄4 當護甲**:`0x13766` 拿防禦者防具的欄4 存進 `ds:9788h`
- 魔法道具那一側是 `0x17C17` / `0x17C1E`([`74`](74-spell-and-item-columns.md) §開頭)

資料側完全吻合:

```
Dagger      欄4=3    Small axe  欄4=4    Short sword 欄4=6    ← 傷害遞增
Chain +1    欄4=6    Plate +1   欄4=8    Plate +2    欄4=9    ← 護甲遞增
Sword +1    欄5=1    Sword +2   欄5=2    Plate +2    欄5=2    ← 就是名字裡的 +N
```

> [`74`](74-spell-and-item-columns.md) §3 當時只能說「那六筆是另一類」。
> 現在知道**分類不在資料裡,在呼叫端** —— 同一欄被兩段不同的程式碼
> 用兩種方式解讀,誰在讀就決定它是什麼意思。
> **「這一欄是什麼」這個問題本身問錯了**;要問的是「誰在讀它」。

## 3. 赤手空拳走另一條路

```
01378B  cmp word ptr [di+6822h], 3Ch   ; 屬性 4[攻] 與 60 比
013790  jge short loc_13795            ; ≥ 60 → 無武器分支
013792  jmp loc_1387D                  ; < 60 → 有武器
```

`60` 正是 [`75`](75-character-record-equipment.md) §3 的「未裝備」哨兵 ——
**同一個常數在初始化端與判定端各出現一次**,兩邊獨立印證。

## 4. 還沒解開的

| 項目 | 已知 | 未知 |
|---|---|---|
| 屬性 9 | 攻擊者的命中基礎,來自 `MONSTERS` 欄3 | 玩家角色那一側從哪個欄位來 |
| 屬性 8 | 怪物固定為常數 `0`([`73`](73-monster-columns-to-combat-array.md) §2)→ 打怪物**永遠** +30 | 玩家角色的值從哪來、代表什麼 |
| 屬性 10 | 怪物固定為常數 `3` → 怪物打怪物**永遠** +12 | 語意未解 |
| 擲骰 | `int 3Dh:34` + `3Fh:77`,骰面上限在 `ds:977Eh` | 命中值怎麼跟骰子比 |

⚠ **「打怪物永遠 +30」聽起來像結論,但它建立在「屬性 8 對怪物是常數 0」上**,
而那是從初始化程式碼讀來的單一路徑。**若有別處會改寫屬性 8,這句就不成立。**
標為**待驗證**,不要當定值引用。
