# 83 — 屬性 3 才是生命值:訂正 [`82`](82-monster-columns-semantics.md)

日期:2026-08-14
接續:[`82-monster-columns-semantics.md`](82-monster-columns-semantics.md)
子系統:**E. 規則資料表** × **J. 戰鬥規則** × **D. 角色資料**

## 結論

[`82`](82-monster-columns-semantics.md) 把 `MONSTERS.DAT` **欄8 判成生命值,而且標了「已確認」。那是錯的。**

**生命值是戰鬥屬性 3**,而它的來源是**欄4**;欄8 餵的屬性 19 在整個 `CMBT` 裡**只被寫、從來沒被讀**。

| | [`82`](82-monster-columns-semantics.md) 寫的 | 正確 |
|---|---|---|
| 欄4 | 「攻擊力?未解」 | **生命值的骰基**(→ 屬性 3)|
| 欄8 | 「**生命值,已確認**」 | **經驗值**(→ 屬性 19,戰鬥中不讀)|

## 1. 決定性的證據:傷害扣在屬性 3 上

```
013A0B  add di, 2Dh              ; + 45 = 屬性 3
013A10  mov bx, ds:9786h         ; 傷害值([`79`](79-alignment-resolved-damage-formula.md) §3 的輸出)
013A14  sub [di+6822h], bx       ; 屬性3[防禦者] −= 傷害
013A18  cmp word ptr [di+6822h], 1
013A22  mov word ptr [di+6822h], 0   ; 不讓它變負
013A33  cmp word ptr [di+6822h], 0
013A38  jg  → 還活著
013A3A  jmp loc_13B36                 ; ≤ 0 → 死亡處理
```

旁邊就是字串 `' damage.'`。**傷害減在哪個欄位上,那個欄位就是生命值** —— 沒有比這更直接的。

怪物那一側:

```
0181A7  mov bx, [di+7834h]   ; 欄4
0181AB  INT 3F:57            ; → 浮點
0181BD  INT 3F:91            ; × 亂數
0181C5  INT 3F:81            ; + ds:9F9Ah
0181D2  INT 3F:85            ; + 亂數
0181E7  mov [di+6822h], bx   ; → 屬性 3
```

角色那一側:屬性 3 ← `CHARS.DAT` 位移 28([`81`](81-chars-record-to-combat-attributes.md))。

**這個不對稱本身就是答案**:角色的當前生命值**存在存檔裡**,
怪物的**每次遭遇現骰**。兩邊餵同一個屬性,一個讀記錄一個擲骰 —— 完全合理。

## 2. 欄8 是經驗值

| 證據 | 內容 |
|---|---|
| 屬性 19 在 `CMBT` 的存取次數 | **1 次,而且是寫入**([`73`](73-monster-columns-to-combat-array.md) 那一筆)—— 整場戰鬥從不讀 |
| `Siriadne !`(最終頭目) | 欄8 = **5000**,而欄4 = 85 |
| 欄8 ÷ 欄4 的中位數 | **4.35**,但頭目是 **58.8** |

**「寫了卻不讀」是一個很強的形狀** —— 那種值是要**帶出戰鬥**給別的模組用的。
頭目那個 5000 打破了與欄4 的固定比例,而經驗值正是設計者會特別給大數的東西。

⚠ **信心:證據充分,不是已確認。** 沒有看到戰鬥結束後把屬性 19 加進角色的程式碼
(那在別的模組)。[`82`](82-monster-columns-semantics.md) 就是在這一步太快下「已確認」。

## 3. 為什麼 [`82`](82-monster-columns-semantics.md) 的測試會過

那兩條等級序列(戰士 33→225、巫師 33→220)**嚴格單調** —— 測試沒錯,
**但單調對生命值成立,對經驗值也成立。**

> **判準:一個測試若對兩個候選答案都會通過,它就不是判別測試。**
> 「隨等級單調上升」在角色扮演遊戲裡幾乎每個數值欄位都成立 ——
> 我拿它當證據,等於沒測。真正能分開的是
> **「這個值被誰讀」**(屬性 3 被傷害扣、屬性 19 沒人讀)。

同一份筆記裡的欄10(法力)測試是**真的判別測試** ——
`Fighter` 全 0、`Wizard` 全非 0,對「生命值」「經驗值」都不成立。
**同一篇裡一個測試有效、一個無效**,差別就在有沒有反例群。
