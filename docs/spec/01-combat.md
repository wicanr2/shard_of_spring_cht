# 戰鬥規則 — **READY**

## 1. 單位陣列

BASIC 二維陣列 `A%(單位, 屬性)`,**行主序**:位址 = `屬性 × 15 + 單位`。
**最多 15 個單位**;隊伍佔索引 **9 – (人數+8)**,怪物佔 0–8。

## 2. 先攻

兩層 0–13 的迴圈,依**屬性 2(速度)**對行動順序表 `ds:6A7Ah` 排序,
**速度高的先動**(`jge` → `SWAP`)。順序表存的是單位編號。

**每回合重排**([`re/159`](../re/159-initiative-resorts-every-round.md)):
排序之前順序表先被重新填成 `0…13`,而排序之後 `inc` 的那個計數器
別處被拿去 `cmp …, 2` —— **整場只跑一次的話那是死碼**。

⚠ 順序表要**重建**再排,不是拿上一回合的順序再排一次 ——
穩定排序下兩者不同:上一回合的次序會變成同速時的排法,而原版沒有那個記憶。

⚠ 信心 **證據充分**:沒有直接讀到「回合結束跳回排序前」的後向跳躍
(可能走 BASIC 的 `GOSUB`/`RETURN`),論證靠的是「死碼不該存在」。

## 3. 行動點數

轉身 **1 點**、其他行動 **3 點**。`Dispell` 需要 3 點。

## 4. 命中

```
命中 = ( 命中能力[攻] − 防具加值[防] + 武器加值[攻] ) × 4
       + 30   若 狀態[防] > 1        (非 OK —— 中毒/被縛/凍結更容易被打中)
       + 12   若 朝向[攻] = 朝向[防] (背後攻擊)

擲骰 ≤ 命中 → 命中;否則 miss
```

「加值」= `ITEMS.DAT` **欄5**。

## 5. 傷害

整段算式已從反組譯讀通([`re/153`](../re/153-damage-formula-closed.md)):

```
持武器   傷害 = 擲骰(武器傷害) − 護甲技能[防] − 防具值 + floor((力量[攻] − 7) × k₁)
赤手     傷害 = 擲骰(力量[攻])  − 護甲技能[防] − 防具值
空手道   傷害 = 擲骰(命中能力[攻] − 5) − 護甲技能[防] − 防具值
```

- **擲骰(N) = `INT(RND × N) + 1`,回 1…N** —— 那個 `+1` 就是 `k₂`(`ds:9464h`),
  引擎的 `Roll(n)` 已經把它折進去
- 「擲骰的面數是哪一項」**就是三條分支的差別**,回傳值分不開它們
- 武器傷害 / 防具值 = `ITEMS.DAT` **欄4**;赤手的判斷式是武器格號 ≥ 60(哨兵 99)
- **防具值對隊員是背包格號 → `ITEMS` 欄4,對怪物是欄 5 的值本身**
- 護甲技能 = 屬性 17(`Armored skin`),**不是狀態效果強度**
- `k₁`(`ds:9460h`)= **0.5** —— 那一項就是手冊 p.11 的 `INT((力量 − 7) / 2)`;
  ⚠ 值本身沒有從檔案讀出,是靠「程式讀到 `−7`、手冊也是 `−7`」定的。
  **1.0 已被排除**:同一個變數在別處被當成機率門檻(`RND < k₁`),
  ≥ 1 會讓那個條件恆真([`re/153`](../re/153-damage-formula-closed.md) §6.2)
- 力量 < 7 時加值是**負的**,而且是 `floor` 不是截斷(`floor(-0.5) = -1`)
- **傷害 < 1 → 不扣血**,原版印 `for no damage.`(讀到了,不是推的)

### 5.1 狂暴加倍

```
攻擊者屬性 16(Berserking)非 0  且  同一次攻擊的第二次擲骰 > 75
    → 傷害 ×2,訊息由 'and hits for' 變成 'and hacks for'
```

**擲骰面數 = 100**([`re/154`](../re/154-die-is-d100.md)):手冊 p.13 的表把命中率
印成 `技巧 × 4` **%**,而程式算的是 `擲骰 ≤ 技巧 × 4` ——
**表裡的數字既是命中值也是百分比,兩者相等只在 100 面時成立**。
狂暴的 `> 75` 因此是四分之一,而 76 這個下界也自動滿足。

⚠ 值本身**沒有從檔案的位元組讀出來**(模組的變數大半不在檔案映像裡)。
信心是證據充分,不是已確認。

⚠ 先前這一節寫的是
`(武器傷害 × R₁ − 狀態效果強度 − 防具值) × k₁ + R₂ + k₂`,
而**力量整個沒有出現、`k₁` 乘的是整個括號、`R₂` 這個第二次擲骰不在傷害裡**。
那個式子算出來的傷害同樣落在合理範圍 —— 分不開,只能讀程式。

## 6. 傷害套用與死亡

```
屬性3[防] −= 傷害
若 屬性3 < 1 → 設為 0
若 屬性3 ≤ 0 → 死亡處理
```

### 6.1 攻擊附帶中毒

打完還活著、而且**防禦者是隊員**(索引 ≥ 9)時再判一次
([`re/191`](../re/191-poison-on-hit.md)):

```
中毒 ⟺ 屬性4[攻] == 62  且  亂數 < 0.15  且  屬性8[防] == 0
     → 屬性8[防] = 1,訊息接上 `and is poisoned!`
```

`62` 是有毒自然武器的哨兵值:`MONSTERS.DAT` 欄5 只有 0–13 與 62 兩群,
62 那一群是眼鏡蛇、死亡蝮蛇、食屍鬼、坑蝮蛇、響尾蛇。
角色取不到 62(`ITEMS.DAT` 只有 57 筆),所以這一支是**怪物咬人**專用。

⚠ **兩道位置閘門在擲骰之前、三個條件在擲骰之後。** 打死了或防禦者是怪物
就完全不進這一段(不消耗亂數);進來之後不論武器是不是 62 都會擲那一顆 ——
把擲骰挪到武器判定底下會改變亂數的消耗順序([`07`](07-combat-scene.md) §8 驗收 6 的同一個坑)。

## 7. 逃跑

**不是指令,是狀態。** 每回合掃隊伍索引 9…(人數+8),
若**沒有任何一個成員的朝向 > 0**(朝向 0 = 不在場)→ 顯示 `'PARTY RAN!'`,
`GROUPS.DAT` 位移 85 清 0,回地圖模組。

⚠ 「把朝向設成 0」那一步的程式碼**未讀到**。

## 8. `Dispell`(指令 `D`)

四個前提:行動點數 ≥ 3、有 `Priesthood` 技能(位移 51)、職業是 `Wizard`、
本場未用過。目標必須是不死生物。

## 未解

屬性 **14** 已解([`re/163`](../re/163-attribute-14-is-action-type.md)):**行動類型**。
隊員由 `CHARS.DAT` 位移 15 的職業字元決定(戰士 → 1、巫師 → 2),
怪物擲 `INT(亂數 × ds:94B8) + 1`。同一個分支順手把屬性 11(圖組)設成 41 / 57。

怪物的擲骰面數 `ds:94B8` = **5**([`re/178`](../re/178-settings-from-three-sources.md) §2,
DGROUP 的編譯期常數),而 1–5 正是五個法術系別
([`re/170`](../re/170-monster-ai-casts-by-spell-family.md))—— 所以對怪物而言
屬性 14 就是**它會放哪一系的法術**。引擎照擲。

⚠ 系別 1 與「隊員 = 戰士」同值。**這不會誤觸空手道閘門** ——
那個閘門的第二層要技能旗標,而怪物沒有技能旗標。

⚠ 空手道的閘門是**兩層**:先看屬性 14 == 1,才去讀角色記錄的技能旗標。
少了外層,巫師空手也會走「命中能力 − 5」那條式子。

屬性 **18** 有形狀了([`re/158`](../re/158-attribute-18-is-a-coin-flipped-preference.md)):
每單位一份的 **±1 偏好**,開場 0、第一次用時擲 50% 硬幣定值(值定了就不再重擲),
遇到某條件會取負。它在移動常式裡選兩條對稱分支中的一條。
⚠ 兩條分支各自做什麼**沒讀完** —— 不要據此實作。
