# 法術系統 — **READY**

## 1. 施法

玩家自己決定**投入幾點法力**(`CAMP` 的 `'Spell Pts ?'`):

```
若 投入點數 < 法術的最低消耗(欄5) → 失敗
威力 = 每點威力(欄4) × 投入點數
```

## 2. 能不能施

`MID$(角色記錄, 系別 + 41, 1) ≠ '0'` —— 角色的技能旗標裡對應的**系別**要開著。
系別 1–5 對應 `Wizard` 技能表的前五項(五種 runes)。

## 3. 狀態類法術

命中時同時寫兩個欄位:

```
狀態[目標]     = 法術系別(欄2)
狀態強度[目標] = 最低消耗(欄5) ÷ 投入量
```

狀態編號 = 系別編號(`OK` 0 / `Poisoned` 1 / `Bound` 2 / `Still Air` 3 /
`Frozen` 4 / `D E A D` 5)。

## 4. 魔法道具

`ITEMS.DAT` 欄4 = 法術編號、欄5 = 投入點數、欄6 = **道具損壞率**
(分母 100,[`re/190`](../re/190-items-col6-is-break-chance.md))。
只有物品編號 > 26 才走這條路。
