# 戰場:15×15、行動點數與離場(M10) — **READY**

對應 [`03-engine-plan.md`](03-engine-plan.md) 的 **M10**。
RE 來源:[`re/140`](../re/140-manual-stat-tables.md) §1/§7(手冊 p.33–35、p.50)、
[`re/103`](../re/103-flee-is-leaving-the-field.md)(逃跑 = 全隊離場)、
[`07-combat-scene.md`](07-combat-scene.md)(單位陣列與命中/傷害)。

## 0. 這一份解掉了 M4 明講的封鎖

[`07`](07-combat-scene.md) §7 把戰場移動列為不做,理由是
「移動與距離判定要先解**攻擊的射程條件**,而 [`01`](01-combat.md) 沒有那一條」。

**手冊 p.34 直接寫著那一條**:`A` 是「攻擊**面前**的敵人」——
近戰、範圍是**朝向的那一格**。封鎖解除。

> **判準**:一個被標成「缺某條規則所以不做」的功能,
> 每次有新來源進來(手冊、實跑)時要回頭問**那一條補上了沒**。
> 這一項擱了四個里程碑,而補上它的那句話在手冊裡只有半行。

## 1. 戰場

```
15 × 15 格,四周一圈是「圓點」
```

⚠ 圓點**不是裝飾**:隊員走上圓點,那一格變成四向箭頭的**出口**,
其他隊員只能從這個出口離場(手冊 p.33)。

本引擎的座標:`(0,0)` 在左上,`x` 往東、`y` 往南 ——
與世界地圖的 `x*103+y` 是**不同的兩件事**,戰場是自己的小格盤,
不索引任何原版檔案,所以怎麼排都可以,取最不容易寫反的那一種。

## 2. 行動點數

```
每回合的點數 = 該單位的速度        (手冊 p.34)
前進 2   轉向 1   攻擊 3   施法/用物品/降魔 3
```

⚠ **施法、用物品、降魔做完直接結束該單位的回合**(手冊 p.35 三條都寫
「會取消行動能力」),**攻擊不會**。四者成本相同,
所以**不能用成本判斷要不要結束回合**([`rules.Action`](../../engine/internal/rules/rules.go))。

手冊 p.48 的「最多走幾格 / 最多攻擊幾次」是這條規則的後果,
18 列逐列吻合([`re/140`](../re/140-manual-stat-tables.md) §1)——
所以這裡實作的是**成因**,不是那張表。

## 3. 攻擊

```
目標 = 朝向的相鄰那一格上的敵對單位
```

- 命中與傷害走 [`07`](07-combat-scene.md) §3 的公式,**不重複**
- **背後攻擊**:兩者朝向相同([`01`](01-combat.md) §4 的 `+12`)
- 那一格沒有單位、或是同陣營 → 這次攻擊不成立,**不扣點數**

⚠ 手冊 p.50 說背後攻擊是 `+3`,而手冊自己的表與反組譯都是 `+12`
([`re/140`](../re/140-manual-stat-tables.md) §3)。以 **+12** 為準。

## 4. 離場與逃跑

```
走上最外圈 → 該單位離場(朝向設 0)
全隊都離場 → 'PARTY RAN!'
```

這與 [`re/103`](../re/103-flee-is-leaving-the-field.md) 從反組譯讀到的
「逃跑不是指令,是狀態:沒有任何成員的朝向 > 0」**完全接得上** ——
反組譯給了判定,手冊給了怎麼觸發。

⚠ **離場 ≠ 死亡**。生命值與朝向是兩個欄位([`07`](07-combat-scene.md) §6),
合併會讓逃跑判定失效。

⚠ 原版的「出口」機制(第一個踩上圓點的人把該格變成出口、其他人只能從那裡走)
**本引擎簡化成任一外圈格都可離場**,並在畫面上標明 ——
出口的獨佔性沒有反組譯佐證,只有手冊一句話,而它影響的是難度不是規則正確性。

## 5. 怪物的行動

⚠ **原版的 AI 未解。** [`07`](07-combat-scene.md) §7 已經把
「目標選擇策略」列為不做,這裡同樣不猜:怪物**朝最近的隊員直線靠近,
相鄰就攻擊**,是一個可預測的佔位。

⚠ 手冊 p.35 提到 `TACTICS` 技能可以看出「怪物正追蹤哪一個同伴」——
所以原版**確實有**目標選擇邏輯,而且是**每隻怪物鎖定一個人**。
本引擎的佔位與那個形狀相容(單一目標),但選法不同。

## 5.1 施法

`C` 開施法選單,施的是**目前輪到的那個人**,不是「全隊第一個會法術的」。
扣 3 點,而且**做完直接結束他的回合**。

⚠ 先前的實作掃全隊找第一個會法術的人 —— 在沒有戰場的 M4/M6 那樣可行,
到了 M10 就錯了:點數是**每個人各自的**,結束回合結束的也是**他的**。
**同一段程式在加進「輪到誰」這個概念之後語意會變**,不會編譯失敗。

⚠ 原版施法要用游標(`I`/`J`/`K`/`M` 移動 + `<SPACE>`)選格子(手冊 p.34)——
本引擎目前仍是「選法術 → 自動挑目標」,**目標選擇未做**。

## 6. 中文化

戰場上的訊息沿用 [`07`](07-combat-scene.md) 的中文;
新增的只有指令提示(移動 / 轉向 / 攻擊 / 結束回合 / 離場)。

## 7. 驗收

| # | 條件 |
|---|---|
| 1 | 行動點數 = 速度;前進扣 2、轉向扣 1、攻擊扣 3 |
| 2 | 點數不足時該動作**做不出來**,而不是變成負數 |
| 3 | 攻擊只打**朝向的那一格**;空格或同陣營時不扣點數 |
| 4 | 施法後該單位的回合直接結束;**攻擊後不會** |
| 5 | 走上最外圈 → 朝向設 0;全隊離場 → `PARTY RAN!` |
| 6 | 兩個單位不能站同一格 |
| 7 | 同一顆種子跑兩次,整場的位置序列完全相同 |
| 8 | 施法扣的是**目前輪到的人**的點數,做完換下一個;點數不足時施不出來 |
