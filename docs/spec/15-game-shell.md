## 1. 原版的主選單:**沒有「開新遊戲」**

`MENU.EXE` 的字串常數逐字如下(`tools/dgroup_strings.py MENU.EXE`):

```
    Main Menu
L)oad a Party.
C)har Utilities.
R)estore Mazes.
I)nstall Game.
P)rogram Notes.
Q)uit the Game.
```

**開局的路徑是兩步**:先進 `C)har Utilities` 造角色、組隊,回主選單再
`L)oad a Party` 選那一隊進遊戲。**沒有一個叫「新遊戲」的入口** ——
「新遊戲」在原版就是「載入一支還沒出過門的隊伍」。

> **這一條決定了 A2/A3 的形狀。** 照抄這個流程,不要自己發明
> 「開新遊戲 / 讀取進度」的二分 —— 那是後來的遊戲才有的概念,
> 而這款遊戲的存檔單位是**隊伍**,不是「進度」。

### 1.1 六項各自怎麼處理

| 原版 | remake | 理由 |
|---|---|---|
| `L)oad a Party.` | **做** —— 列出五個隊伍槽,選一個進世界地圖 | 開局的唯一入口 |
| `C)har Utilities.` | **做** —— 已實作(`roster_scene.go` / `create_scene.go`),只差從主選單進得去 | |
| `R)estore Mazes.` | ⛔ **不做** | 那是把 `DE*EFF` 從 BOOT 磁片複製回 GAME 磁片(字串寫著 `Insert BOOT disk for file # of 9`)。remake 沒有磁片 |
| `I)nstall Game.` | ⛔ **不做** | 安裝到硬碟。remake 的對應物是 `cmd/convert` |
| `P)rogram Notes.` | **做** —— 改成**遊戲內說明**(按鍵表)| 原版是作者的話;remake 沒有紙本鍵盤模板,這個位置正好放按鍵表 |
| `Q)uit the Game.` | **做** | |

⛔ **開機的手冊查表題不做**(`CLAUDE.md` §1「不協助破解 DRM」的另一面:
remake 不需要 1986 年的防拷)。

## 2. 場景與轉移

```
        ┌──────────┐
        │ 標題畫面  │  任意鍵
        └────┬─────┘
             ↓
        ┌──────────┐  C ┌──────────────┐
        │ 主選單    │───→│ 角色管理      │(已實作)
        │          │←───│ 名冊/創角/組隊 │  ESC
        │          │  L └──────────────┘
        └────┬─────┘
             ↓  選隊伍槽 1–5
        ┌──────────────────────────────┐
        │ 遊戲中(世界地圖 / 迷宮 / 戰鬥 / 城鎮)│
        └────┬───────────────┬─────────┘
             │ 全滅          │ 打倒 Siriadne
             ↓               ↓
        ┌──────────┐    ┌──────────┐
        │ 全滅畫面  │    │ 結局畫面  │
        └────┬─────┘    └────┬─────┘
             └──── 任意鍵 ────┴──→ 回主選單
```

⚠ **`Q)uit` 之外沒有其他離開遊戲的路徑。** 遊戲中按 `ESC` 回不到主選單 ——
原版的遊戲中沒有這個功能,而加一個「回主選單」等於加一個原版沒有的存檔點。
**要離開就存檔再關視窗**(存檔是營地的 `S`,見 [`06`](06-party-and-save.md))。

## 3. A1 標題畫面

| 項目 | 內容 |
|---|---|
| 背景 | ✅ **`STARTUP.BIN` 已轉出**(`assets/gfx/startup.png`)。它是 CGA 的**整頁顯示緩衝**(掃描線分兩區交錯,[`re/20`](../re/20-cga-layout.md)),**不是 `GET` 陣列** —— 用 `DecodeTile` 解不會報錯,只會得到一張雜訊。解碼在 `original.DecodeCGAPage`,調色盤跟 `MENU` 走(`0x3D8 = 0x0E`)|
| 版面 | **左圖右文**,照原版。原版整頁的右半是英文製作群,remake **只取左半**(`main.go` 的 `TitleArtPanelW = 158`),右半自己用中文畫 —— 兩份疊在一起會互相蓋掉。<br>⚠ 158 是**量出來的**:掃過整頁只有第 0 欄與第 158–162 欄整欄全黑。改圖之後要重量。<br>⚠ 放大 **3×** 不是 4×:原圖 200 高,4× 之後 800 > 畫面的 768 |
| 文字 | 遊戲名(中文 + 原文)、版本、「按任意鍵」 |
| 音樂 | **沒有**。全遊戲只有通關曲與死亡曲兩首([`re/216`](../re/216-the-game-has-two-tunes.md))——標題畫面在原版是安靜的,不是「還沒接」|
| 離開 | 任意鍵 → 主選單 |

⚠ **`g.titleArt == nil`(圖不在)就退回置中的純文字標題**,不要拿一張全黑的圖
或別的圖冒充(同 `cmd/convert` 對缺圖的處理:用佔位符,不要偷偷補圖)。

⚠ 左圖右文只剩半個畫面寬,**三段文字都要換行**(`ui.Wrap`,寬度 24)——
`drawCenter` 不裁切,太長的那一句會直接畫到畫面外,
看起來像被切掉、不像沒換行。

## 4. A2 主選單

```
主視野      標題 + 四個選項(L / C / P / Q)
指令提示列  按鍵說明
```

| 鍵 | 動作 |
|---|---|
| `L` | 進隊伍選擇(§5) |
| `C` | 進角色管理(現有的 `openRoster()`) |
| `P` | 顯示按鍵表覆蓋層([`04`](04-display-layout.md) §3 的覆蓋層) |
| `Q` | 離開程式 |

⚠ **`C` 與角色管理之間要能回來。** 現在 `roster_scene.go` 的 ESC 直接關掉名冊;
從主選單進去的話 ESC 要回主選單,從遊戲中進去(`N` 鍵)要回遊戲。
**呼叫端決定回哪裡**,不要讓名冊自己記。

## 5. A3 隊伍選擇 = 開局

列出五個隊伍槽:

| 狀態 | 顯示 | 可否選 |
|---|---|---|
| 有資料 | 隊伍編號 + 成員名 + 等級 + 位置 | ✅ |
| 未初始化 | `(空)` | ❌ —— 先去 `C)har Utilities` 組隊 |

**未初始化的判定是「整筆記錄全為 `0x20`」**([`06`](06-party-and-save.md) §「未初始化的判定」)。
⛔ **不要判座標是不是 (8224,8224)** —— 那是症狀不是原因,而且合法座標理論上撞得到。

### 5.1 新組的隊伍從哪裡開始:**大半已解**([`re/232`](../re/232-new-party-initial-values.md))

`CHARUTIL 0x12043`–`0x12132` 對隊伍記錄連寫**八個欄位**,全部是立即數:

| 位移 | 欄位 | 值 |
|---:|---|---:|
| 35 / 37 | 世界座標 | **8, 8** |
| 41 | 朝向 | **3**(南)|
| 59 / 61 | 能見度(有光 / 無光)| **2 / 2** |
| 65 | 拉利斯之門旗標 | 0 |
| 83 | 當前迷宮編號 | **99**(不在迷宮)|
| 69 | 未命名 | 0 |

**座標與朝向從具名假設升級成已確認。** 先前「照抄出貨 PARTY #5」的猜法
**猜對了** —— 但那是猜對,不是知道。
⚠ 能見度**兩欄原版都填 2**,而 PARTY #5 的「有光」是 3(那支被玩過)。

⚠ **金幣、補給品、時鐘、遭遇倒數不在那一段裡**,`CHARUTIL` 也沒有別的
常數位移寫入 —— 這四項**仍然是具名假設**。金幣是 MBF 單精度,寫法不同,
所以那個掃法結構上抓不到它:⛔ 不要把「沒掃到」讀成「沒有人寫」
([`re/232`](../re/232-new-party-initial-values.md) §3)。

### 5.2 ⚠ 沒被覆寫的欄位是 **8224 不是 0**

這筆記錄是從**整份 `0x20` 的空白記錄**解出來的,每個沒被明寫的 word 都是
`CVI(" ") = 8224`。所以初值不能只填「玩家看得到的那幾項」——
`LightTurns` / `MazeNum` / `PoolUses` / `MazeX` / `MazeY` / `Fled` 全部要明寫。

⚠ **漏掉的症狀很晚才出現**:新隊伍在世界地圖上完全正常,
直到第一次查光源或進迷宮才會看到 8224。

⚠ **`MazeNum`(位移 83)的「不在迷宮」是 `99` 不是 `0`**
([`../formats/02`](../formats/02-groups-dat.md))—— 填 0 等於說「在第 0 座地城」,
於是新隊伍一開始就套上地城的規則(火把會燒、能見度走位移 59/61)。
**哨兵值不要當成零值。**

## 6. A4 全滅

```
觸發   combat.Outcome() == combat.PartyDead
畫面   「全隊陣亡」+ 死亡曲(music.Userlib)+ 按任意鍵
之後   回主選單
```

⚠ **現況是錯的**:現在只播一段曲子,按 `ESC` 之後**帶著死掉的隊伍回世界地圖**,
可以繼續走路。要改成上面那條路徑。

⚠ **不要自動讀檔**。原版的存檔單位是隊伍,而隊伍的死亡狀態就寫在 `CHARS.DAT` 裡 ——
玩家想反悔就是重新載入那支隊伍(回到上次存檔的狀態)。

## 7. A5 結局

```
觸發   迷宮事件目標 533(maze.TargetFinalBoss)的戰鬥打贏
```

| 項目 | 內容 |
|---|---|
| 畫面 | 結局文字 + `PICT` 其中一張?⚠ **哪一張未查**([`re/127`](../re/127-pict-contents.md) 五張分別是藏寶圖、NPC 場景、風景、死亡畫面、兜帽人物)|
| 音樂 | `music.Ending`。⚠ 用途是位置上的推測([`13`](13-sound.md))|
| 文字 | ⚠ **原版的結局文字在哪未查** —— `USERLIB` 有結局匯出槽([`re/66`](../re/66-userlib-slot-semantics.md)),但文字本身沒盤到 |
| 之後 | 按任意鍵 → 回主選單 |

⚠ **結局文字查不到就先用一段自己寫的中文**,並在旁邊標明「原版文字未盤到」。
⛔ 不要假裝那是原版的文字。

## 8. A6 按鍵表

一張覆蓋層,列出各畫面的按鍵。來源是手冊 p.50–51 的兩張表
(`COMBAT OPTIONS` / `OUTSIDE OPTIONS`)加上引擎自己的鍵。

⚠ 手冊 p.51 的 `OUTSIDE OPTIONS` **與 DOS 版不符**(寫 `←`/`→` 轉向、`<RETURN>` 前進;
DOS 版是方向鍵先轉再走,[`re/139`](../re/139-oracle-reaches-gameplay.md) §4 實測)——
**以實跑為準**,按鍵表要寫引擎實際的行為。

## 9. 驗收

| # | 條件 |
|---|---|
| 1 | 啟動後看到標題,任意鍵進主選單 —— **不再直接跳進世界地圖** |
| 2 | 主選單四個鍵各有反應;`Q` 真的關掉程式 |
| 3 | `C` 進角色管理,ESC **回主選單**;遊戲中按 `N` 進去,ESC **回遊戲** |
| 4 | 隊伍選擇列出五槽,未初始化的顯示 `(空)` 且選不下去 |
| 5 | 選一支有資料的隊伍 → 進世界地圖,座標/時鐘/金幣來自該槽 |
| 6 | 全滅 → 全滅畫面 → 回主選單。**不能帶著死掉的隊伍繼續走路** |
| 7 | 打倒目標 533 → 結局畫面 → 回主選單 |
| 8 | 上面每一條都有一個**不需要開視窗**的測試(直接呼叫 `Update()`,不跑 `RunGame`) |

⚠ 第 8 條是硬要求。`package main` 現在**一個測試都沒有**,
而這一段全是狀態機 —— 狀態機沒有測試,回歸只能靠人眼。
