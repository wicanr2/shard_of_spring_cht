# 字型:兩個版本

> 狀態:**READY**(2026-08-16 定案)。上位規格是
> [`04-display-layout.md`](04-display-layout.md) §4;本檔補的是「怎麼做出來」。

引擎有兩套字型,由 build tag 決定,**畫面不一樣**:

| 版本 | 指令 | 字型 | 用途 |
|---|---|---|---|
| 發行版(預設)| `tools/go.sh build` | 開源向量字(思源黑體等) | 打包給玩家 |
| 本機版 | `tools/go.sh build -tags eten` | 倚天中文系統 3.53 的 24×24 明體點陣字 | 自己玩、看年代感 |

⛔ **本機版不能發行。** 倚天中文系統是 1993 年的商業軟體,著作權不屬於本專案 ——
`CLAUDE.md` §1 與 [`04`](04-display-layout.md) §4:公開產出只有引擎程式碼與翻譯文本。
字型資產(`engine/assets/font/eten24.bin`)因此 **gitignore**,
`-tags eten` 少了那個檔會**編不起來**;⚠ 這是刻意的 ——
編得起來但沒有字,會變成一個畫面全空、原因看不出來的執行檔。

---

## 1. 為什麼是倚天

《春之石》的官方中文說明書是精訊 1987 年出的([`docs/manual/`](../manual/README.md)),
而那個年代台灣 PC 上的中文就是倚天。**譯名照精訊、字面照倚天**是同一個決定的兩半。

技術上也剛好對得上:倚天 24×24 的全形 24 px 正是 [`04`](04-display-layout.md) §4
的敘述覆蓋層字級,半形 12 px 是它的一半 —— 點陣字**等寬**,欄寬預算變成除法,
沒有估計成分。

## 2. 來源檔案

倚天中文系統 3.53 光碟(`ET353S.iso`)裡的三個檔:

| 檔案 | 內容 | 版面 | 位置 |
|---|---|---|---|
| `STD.24M` | 漢字 13,094 字(明體) | `ETUNPACK V1.00` 壓縮 | DISK4 |
| `SPCFONT.24` | 符號 408 字(Big5 `A140`–`A3BF`,全形標點在這裡) | 24×24,72 B/字 | DISK1 |
| `ASCFONT.24` | 半形 256 字 | **12×24 存成 2 B/列**(右邊 4 位是墊的) | DISK1 |

⚠ 光碟上還有五套字體(楷 `K`、隸 `L`、宋 `S`、黑 `B`、圓 `R`),同樣的格式。
本專案用**明體 `M`** —— 內文字體,筆畫最不搶戲。

### 解包

`STD.24M` 的資料是高熵的(壓縮比 0.70),**不是 RLE,不要試圖直接讀**。
光碟 DISK2 有官方解包器 `ETUNPACK.EXE`,DOSBox 跑一次就好:

```bash
# 工作目錄放 ETUNPACK.EXE 與 STD.24M,DEMON.BAT 內容是「ETUNPACK STD.24M」
docker run --rm -v "$PWD/work:/game" -v "$PWD/shots:/shots" \
  demwin-dosbox:latest cga "wait:20;shot:unpack" "fixed 20000"
```

輸出 `STDFONT.24`,942,768 bytes = 13,094 字 × 72 B。

## 3. 索引:Big5 的緊密編號

低位元組的合法範圍是 `0x40`–`0x7E` 與 `0xA1`–`0xFE`(每個高位元組 157 個):

```
索引 = (hi − 起始hi) × 157 + (lo ≤ 0x7E ? lo − 0x40 : lo − 0xA1 + 63)
起始碼:漢字 A440、符號 A140
```

驗證:索引 0 畫出來是「一」、索引 1 是「乙」。

⚠ **漢字檔跳過常用區與次常用區之間的空洞。** 常用字止於 `C67E`、次常用字始於
`C940`,中間 408 個碼位(`C6A1`–`C8FE`,倚天放日文假名、俄文、線條符號)
在另一個檔 `SPCFSUPP.24` 裡。所以 `code ≥ C940` 的索引要**減 408**。

> 不減的症狀:**前面一萬兩千多字全部正確**,只有最罕用的尾端 367 字
> (驉…鰲)算到檔案外面。錯得剛好夠隱蔽。

本專案的文字沒有任何一個字落在空洞區(掃過 `assets/`、`engine/`、
`translations/` 共 1,422 個非 ASCII 字種),所以不載入 `SPCFSUPP.24`。

## 4. 轉換與資產格式

```bash
tools/eten_font.py <倚天字型目錄> engine/assets/font/eten24.bin
```

輸出 13,550 字、1.14 MB,格式寫在腳本的 docstring。一個要點:

⚠ **每列的位元組數(`row_bytes`)由資產明寫,不讓讀取端從寬度推。**
全形 24 位元剛好 3 B,半形卻是 12 位元存在 2 B 裡 —— 同一條公式湊不出這兩個,
而推錯的症狀是**漢字變成雜訊、ASCII 完全正常**(半形那條剛好推對)。

### 缺字代換

倚天是 **Big5** 的,而引擎介面用了幾個 Unicode 裝飾符號。
`internal/render/bitmap.go` 的 `substitute` 表把它們換成同義的 Big5 字:

| 原字 | 換成 | 用途 |
|---|---|---|
| `⚠` | `※` | 未解項的注意記號(17 處) |
| `✓` | `○` | 打勾 |
| `✚` | `＋` | 施法游標 |
| `▶` | `▲` | 指標 |
| `～` | `〜` | 波浪 |
| `‰` | `％` | 千分號(Big5 沒有) |

⚠ **這是字型層的代換,不是改文字** —— 原始字串仍然是 `⚠`,開源字型那一版照樣畫得出來。
⚠ 少一個記號**不會有人發現**:「金幣公式未解」少了前面那個符號,整句話看起來仍然通順。

## 5. 欄寬預算跟著字型走

`internal/layout` 的欄寬常數分兩個檔(`cols_ttf.go` / `cols_eten.go`):

| | 發行版(半形 10 px) | 本機版(半形 12 px) |
|---|---:|---:|
| 訊息面板 `MsgCols` | 30 | 25 |
| 主視野 `ViewCols` | 58 | 48 |
| 提示列 `PromptCols` | 96 | 80 |

**換字型就換一整組** —— 「一行放得下幾個字」直接決定清單放不放得下。

### 字級換大之後修掉的三處

| 問題 | 修法 |
|---|---|
| 提示列第二行掉出面板 | 面板 84 → **108 px**(兩行 24 px 字 + 內距),說明折行到 `PromptCols`,並把 `combat.GoldAssumption` 縮短到一行 |
| 戰鬥的單位表滿出主視野 | 收邊,**並印「…還有 N 個單位」** —— ⛔ 不可以默默截斷。溢出時先丟隊員(他們的 HP 右側欄本來就有),怪物一定看得到 |
| 裝飾符號變空白 | 上一節的代換表 |

## 6. 兩個版本都要驗

```bash
tools/go.sh test -count=1 ./...              # 發行版
tools/go.sh test -count=1 -tags eten ./...   # 本機版
SHOT_DIR=… SHOT_ASSETS=/assets SHARD_NOSOUND=1 \
  tools/go.sh test -count=1 [-tags eten] -run TestShots .
```

`docs/images/` 收的是**發行版**的畫面(玩家看到的那一套);
本機版另存一張對照:[`06-combat-eten.png`](../images/06-combat-eten.png)。
