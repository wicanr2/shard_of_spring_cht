# 手繪冒險書現代主題 — **READY**

> 2026-08-20 由專案負責人確認：視覺與配樂分開切換；現代美術採手繪
> 冒險書方向；正式流程允許生成式 AI 初稿，再由可重生工具做人工指定的
> 切片、去背、錨點與原版輪廓疊合。

## 1. 玩家契約

- `F5` 維持配樂「原版／重製／關閉」三段切換。
- `F6` 獨立切換視覺「原版／手繪冒險書」，兩者可任意混搭。
- 視覺偏好寫入存檔目錄旁的 `config.json`，欄位為 `visual`；合法值只有
  `original` 與 `storybook`。缺欄、未知值或舊設定檔一律退回原版。
- 原版仍是預設與 parity 驗收基準；現代主題明確標示為重製增補。

## 2. 資產群組

現代資產由 `engine/assets/modern/` 內嵌進執行檔，不依賴玩家由原版轉出的
`assets/`。主題群組包含：

- `title.png`：標題與 logo；
- `world/tNN.png`：68×68 世界圖塊；
- `world_auto/`：現代世界自然地形的 4×4 連續材質頁；森林與海岸各有
  北／東／南／西 4-bit 的 16 種鄰接遮罩；
- `maze/tNN.png`：68×68 迷宮圖塊；
- `combat/cN.png`：68×68 戰場／法術圖塊；
- `walk/wN.png`：帳篷與四方向兩步態玩家 sprite；
- `monst/monstNN.png`：22 組怪物 sprite。

載入時整組預載；遊戲中只切換已載入 map 的指標選擇，不在畫格中讀檔。
原版與現代資產的索引、方向、碰撞、事件與秘密資訊語意不得漂移。

## 3. 視覺語言

- 1024×768 與既有四區塊幾何不變，避免 UI 美化改動正常玩家路徑。
- 現代 UI 使用羊皮紙面板、深褐墨線雙框、赭石與森林色、水彩插畫。
- 現代主視野的未照明、視距外及未繪製區使用深褐黑 `#1d1610`；羊皮紙色
  只留在資訊與操作面板，不把黑暗誤畫成大片土黃色。
- 原版 17×17 圖塊仍以 4× 最近鄰顯示；現代圖塊直接以 68×68 顯示。
- 現代世界的海洋、海岸、草原與森林依世界絕對座標及四向鄰格自動拼接；
  只改顯示，不改原版地形值、碰撞、事件、秘密資訊、移動格或存檔格式。
- 海岸遮罩只讀相鄰海洋，森林遮罩只讀相鄰森林；城鎮、地城入口、山地與
  特殊索引仍使用單格資產，避免美術分類猜測未知語意。
- 未知地形不猜語意：水彩底材上疊回原版非黑輪廓，保留索引與資訊。
- 標題現代插畫使用線性縮放與置中裁切；原版 title 仍走整數倍最近鄰。

## 4. 來源、重生與權利

- 候選母稿與生成紀錄在 `art/modern/`。
- `tools/build_modern_assets.py` 只能在 `mm2-pil:pillow11` Docker image 內執行；
  映像由鎖版的 `tools/docker/pillow.Dockerfile` 重建。腳本產生 68×68 單格資產
  與 272×272（4×4 格）的現代世界連續材質頁。
- 公開或商用發行前，重新確認當時的 OpenAI 輸出條款、使用權、人工修改紀錄
  與第三方相似性；不可把現代美術稱為原版修復或未發表原畫。

## 5. 驗收

1. `tools/go.sh test -count=1` 與 `-tags eten` 兩套全綠。
2. 原版與現代各拍標題、主選單、世界、城鎮、迷宮、營地、戰鬥、戰場地形、
   按鍵表九畫面；現代主題不得有遮字、低對比、缺 sprite 或混入錯誤索引。
3. `F6` 來回切換後，場景、位置、存檔與配樂模式都不變；重開遊戲讀回偏好。
4. 三平台發行包不得含原版 `assets/`，但必須顯示內嵌現代主題。
5. 自動拼接資產必須完整包含兩種自然底材及森林／海岸各 16 種遮罩；抽樣
   世界實機截圖不得出現母稿格線、逐格鏡射、色帶或半載入混搭。
